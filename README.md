# STACKFALL

장비를 중첩해 공격 방식과 우주 전장을 변화시키며 버티는 웹 생존 액션 게임입니다.

- 저장소: `q93503128-a11y/Stackfall`
- 배포: `https://stackfall.pages.dev`
- 실행 환경: 정적 HTML/CSS/JavaScript
- 게임 로직: JavaScript
- 기본 화면: Canvas 2D
- 대량 아군 투사체·전투 파티클: PixiJS WebGL
- WebGL 초기화나 CDN 로드에 실패하면 Canvas 2D로 자동 복귀

## 실행

루트 폴더에서 정적 웹 서버를 실행합니다.

```bash
python -m http.server 8000
```

그다음 브라우저에서 `http://localhost:8000`을 엽니다.

## 에코 비콘

원본 공격과 복제 공격이 완전히 겹치지 않도록 복제 공격은 약 64~91ms 뒤 발동합니다. 고중첩에서 추가 복제가 발생하면 첫 복제보다 다시 약 90~120ms 늦게 발동합니다. 복제 공격은 분홍색 계열로 구분합니다.

## 설정

- 언어
- 음향 채널별 켜기·끄기
- 음향 채널별 음량
- 피해량 표시
- 아군 투사체 숨기기
- 반짝임 효과
- 화면 흔들림

최종 출력 gain은 `2.76`이며 채널 곡선·개별 profile·에코 send를 거친 신호를 threshold `-20dB`, ratio `4.5:1`, knee `22dB`의 컴프레서로 제한합니다. 직전 커밋에는 출력 gain `3.24`와 추가 `1.24배` wrapper가 함께 있었으므로 현재 값을 “직전 빌드 대비 +6dB”라고 표현하지 않습니다. 현재 설계는 단순 증폭보다 공격음의 고역 가독성, 무기별 음색 분리와 피크 억제를 우선합니다.

배경음은 일반 전투, 맵 이벤트, 초월체 전투의 세 장면으로 나뉘며 전투 상태가 바뀌면 자동 전환됩니다. 같은 장면을 반복 동기화해도 ambient interval은 하나만 유지하고, 장면 변경·비활성화 시 이전 node와 timer를 정리합니다. 레벨업 효과음은 높은 상승음 대신 220Hz에서 82.41Hz로 내려가는 저역 음형, low-pass와 41.2Hz sub tone을 사용합니다. 공격음은 높은 대역을 보강하고 코어·칼날·중력·레일 등 15개 무기 계열마다 주파수, 파형, 길이와 피치 이동을 다르게 사용합니다.

`반짝임 효과`를 끄면 장식용 전투 파티클, 화면 섬광, 별의 점멸과 긴 광원 꼬리를 줄이거나 제거합니다. 적 투사체, 보스 장판, 공격 예고 등 생존에 필요한 표시는 유지합니다.

## 맵 이벤트 제한과 초월체 우선순위

- 이벤트 표식은 46초 뒤 소멸하고 해당 이벤트를 다시 예약하므로 다른 이벤트를 영구 차단하지 않습니다.
- 성운 보관소·우주선 잔해·공허 선택 화면은 전투와 게임 시간이 멈추므로 자동 선택 제한시간을 사용하지 않습니다.
- 추락한 우주선 전투 제한은 82초, 공허 균열 보스 제한은 108초입니다. 실패하면 전용 적·탄막·예고를 정리하고 다음 이벤트를 예약합니다.
- 초월체 예정 시각은 실제 게임 시간만 사용합니다. 일시정지·능력 선택·보상·이벤트 선택·등장 연출 중에는 게임 시간과 초월체 시계가 함께 멈추며, 누적 게임 시간이 8분·16분·24분에 도달했을 때만 일반 이벤트보다 우선해 등장합니다.
- 초월체 전투는 전용 봉쇄장 안에서 진행되며 초월체는 넉백, 중력 흡입, 시간 정지와 이동 봉쇄에 면역입니다.
- 시간포식자는 부서진 시계판과 시간 절단, 종말 항성은 거대 고정 용광로와 회전 화염선, 마지막 성좌는 소형 본체와 거대 별자리 격자 패턴을 사용합니다.

## 렌더링과 성능

게임 규칙·충돌·AI·보상은 기존 JavaScript 상태 배열을 그대로 사용합니다. 렌더링만 분리했습니다.

### PixiJS WebGL 담당

- 아군 투사체
- 장식용 전투 파티클
- 무기 계열별 실루엣 텍스처를 공유하는 스프라이트 배칭
- GPU 가속 위치·회전·크기 갱신
- 코어·별빛·혜성·파편·범용 탄환의 소스별 텍스처 수명 관리

### 배경 Canvas 2D 담당

- 배경과 성운
- 중력 우물과 비위험 아군 특수효과

### 전경 Canvas 2D 담당

- 적과 보스
- 적 투사체
- 위험 예고
- 플레이어
- 광선과 중요 전경 효과
- UI와 안내

화면 계층은 `배경 Canvas(z=0) → PixiJS 아군 효과(z=1) → 전경 Canvas(z=2) → HTML UI(z≥10)` 순서입니다. 세 렌더 계층은 프레임마다 한 번 계산한 `shakeX`, `shakeY`를 함께 사용합니다.

PixiJS는 버전 `8.19.0`을 고정해서 불러옵니다. 렌더러 상태는 `loading`, `warming-up`, `active`, `failed`, `context-lost`, `canvas-fallback`으로 관리합니다. PixiJS 로드, GPU 캔버스 삽입, 0이 아닌 캔버스 크기, ticker 실행, 첫 GPU 프레임, 실제 투사체 sprite 표시가 확인된 뒤에만 Canvas 2D 아군 투사체 렌더링을 멈춥니다. WebGL 컨텍스트가 복구되면 기존 텍스처를 sprite에서 분리하고 파괴한 뒤 새 텍스처를 연결합니다. Pixi app, ticker, 캔버스와 context listener는 다시 만들거나 중복 등록하지 않습니다.

로드 실패, 초기화 실패, WebGL 미지원, WebGL 컨텍스트 손실, 투사체 sprite warm-up 실패가 발생하면 게임을 중단하지 않고 기존 Canvas 2D 투사체 렌더러로 자동 복귀합니다. `window.stackfallRendererInfo()`는 계층·DPR·공유 shake·컨텍스트 복구 횟수·ticker·sprite pool을, `window.stackfallRuntimeDiagnostics()`는 반복 오류·예약 공격·개체 수를 콘솔 진단용으로 반환합니다.

기존 최적화도 유지합니다.

- 공간 해시 충돌 검사
- 유한 사거리 표적의 인접 셀 탐색
- 적 ID 색인
- 가까운 소수 표적의 부분 삽입 선택
- 투사체 객체 풀링
- 경험치 결정 병합
- 화면 밖 개체 렌더링 생략
- 캐시된 Canvas 스프라이트
- 효과 배열 제자리 압축
- 런 세대와 게임 시간 기반 예약 공격
- 심한 부하에서만 최후 수단 해상도 조절

전투 예약기는 한 업데이트에서 만료된 callback마다 현재 런 세대와 `playing` 상태를 다시 검사합니다. 앞 callback이 reset·메뉴·게임 오버를 일으키면 같은 batch의 나머지는 실행하지 않으며, callback 안에서 새로 예약한 공격은 다음 업데이트부터 실행합니다. 일시정지·선택·보상·이벤트 중에는 남은 시간이 줄지 않고, cinematic 진입과 런 종료 시 queue를 비웁니다.

## 로딩 순서 주의

최종 렌더링 관련 순서는 반드시 아래를 유지합니다.

```text
dark-cosmic-polish.js
performance-guard.js
build-audit-ui.js
gpu-renderer.js
```

`performance-guard.js`가 적 렌더러를 교체한 뒤 `build-audit-ui.js`가 정예 종류 표시와 원거리 적 표시를 감싸야 합니다. 순서를 반대로 바꾸면 중간보스·보스 표시가 사라질 수 있습니다. `gpu-renderer.js`는 마지막에 WebGL 전투 레이어와 전경 Canvas를 연결합니다.

구식 임시 덮어쓰기 파일은 정식 소유 모듈로 통합했습니다.

- 투사체 유도와 빔 수명: `systems.js`
- 원거리 적과 시간 정지 이동: `bosses.js`
- 빔·중력 우물·플레이어 렌더링: `render-entities.js`
- 장비 공전 외형과 중력 렌즈: `render-entities.js`
- 프리즘 발사·집속·배율: `weapons.js`, 보상 정의: `reward-refinement.js`
- 부메랑 생성: `weapons.js`, 갱신·충돌: `systems.js`, 렌더링: `render-entities.js`
- 보상 중복 방지와 강화 보정: `reward-refinement.js`
- 예약 공격과 UI 타이머: `systems-base.js`
- 공간 색인과 가까운 표적 조회: `performance-guard.js`
- 일반·이벤트 중장갑 공용 형상 helper와 Canvas 폴백 적 렌더: `render-entities.js`
- 최종 캐시 적 렌더 진입점: `performance-guard.js`
- 원거리 적 오버레이와 정예·화면 밖 표시: `build-audit-ui.js`
- 맵 이벤트 형상: `dark-cosmic-polish.js`, 최종 이벤트 표시 래퍼: `build-audit-ui.js`
- 런타임 진단과 단일 RAF: `render.js`
- 장면별 BGM과 무기별 공격음: `runtime-config.js`, 장면 동기화 호출: `render.js`
- GPU fallback, texture 수명과 sprite pool: `gpu-renderer.js`

삭제된 구식 파일:

- `src/projectile-overrides.js`
- `src/visual-overrides.js`
- `src/feature-hotfix.js`
- `src/reward-refinement-fix.js`
- `src/boomerang-return-fix.js`

세부 수치, 등장 규칙, 보상, 이벤트, 성능 원칙과 QA 항목은 `docs/GAME_DESIGN.md`를 기준으로 합니다. 플레이 방법과 무기·보스 설명은 [`docs/WIKI.md`](docs/WIKI.md)에 정리합니다.

브라우저 회귀 검사는 로컬 서버를 켠 뒤 `node scripts/browser-smoke.mjs`로 실행합니다. 예상하지 않은 warning/error/예외/네트워크 실패는 테스트 실패이며 결과는 무시되는 `test-results/stackfall-smoke.json`에 저장됩니다. 정상 GPU와 `WEBGL_lose_context`는 기본 필수이고, 명시적인 환경변수 `STACKFALL_ALLOW_GPU_SKIP=1`, `STACKFALL_ALLOW_CONTEXT_SKIP=1`에서만 사유가 포함된 skip을 허용합니다.

2분 고밀도 검사는 플랫폼 공통으로 아래처럼 실행합니다.

```bash
node scripts/browser-smoke.mjs --soak-ms=120000
```

## Difficulty and weapon augment audit

- The main menu offers Easy, Normal, and Hard. Normal is the reference balance; the current reference enemy health curve is reduced by 8% before difficulty modifiers.
- Ranged enemies begin appearing later and their normal-mode share is capped below the previous value.
- Every weapon, including Ion Chain, Nova Pulse, Meteor Drones, Rail, Galactic Spiral, and Reflector, has a dedicated boss-reward augment. Nebula Boomerang kills can leap from the defeated target to a random nearby enemy.
- The ability ledger can be opened while a level-up choice is waiting. Combat remains paused and the same choice cards are restored on close.
- Random upgrade notices remain visible two seconds longer. Elite and mini-boss labels are not drawn over the battlefield; their category and name are shown only in the top boss HUD.

### 후반 위협·프리즘·선택 조작

- 성좌 프리즘은 0.25초 기본 피해 틱을 사용하며 공격 주기 감소가 틱 간격을 줄인다. 최대 출력 배율을 낮추고 공격 펄스 사이에 시각적 공백을 둔다.
- 일반 무기 피해는 프리즘을 제외하고 8% 상향하며, 4분 이후 위협 단계에 따라 적 피해와 이동 속도가 추가 상승한다.
- 이벤트 능력 선택지는 전투가 멈추므로 자동 선택 제한시간을 사용하지 않는다.
- 레벨업·보스 보상·이벤트 선택지는 숫자 1·2·3으로 선택할 수 있고 카드에 단축키를 표시한다.
- 다중 투영 코어는 최대 2중첩의 이벤트 전용 패시브다. 탄환·펄스 블레이드·중력 우물·성좌 프리즘·유성 드론·레일 광선·은하 나선의 실제 공격체를 중첩당 하나 추가하며, 파동·장판·반사·연쇄 공격은 제외한다. 일반 레벨업 풀에는 등장하지 않는다.
- 초월체 등장 간격은 480초(8분)다.

### 맵 전환·장기 특수효과·무제한 위협 성장

- 효과 설명에는 실제 전투 수치나 판정 변화만 기록한다. 단순 외형·광원·장식 변화는 효과로 표기하지 않는다.
- 일식 동력로는 상시 피해 +20%이며, 체력 50% 미만부터 추가 피해가 증가해 체력 30% 이하에서 총 최대 +50%가 된다.
- 보스 보상은 최대 4개 카드로 표시하며 무기 특수효과는 현재 보유한 무기에 대해서만 생성한다. 각 무기는 고유 특수효과 하나만 가지며 한 판에 한 번만 획득할 수 있다. 무기 특수효과는 단순 피해·주기 수치가 아니라 추가 공격, 반격, 붕괴, 도약, 추적 등 실제 전투 동작을 추가한다.
- 공허 및 초월체 맵 전환은 단일 전환 소유권과 일련번호를 사용한다. 이전 전환의 지연 콜백은 새 전환이나 복귀 배경을 덮어쓸 수 없다.
- 4분 이후 적 피해·속도는 상한이나 로그함수 없이 선형항과 거듭제곱항으로 계속 증가한다. 적 체력 성장 역시 기존의 무제한 거듭제곱 성장을 유지한다.
- 재생 장갑은 중첩당 최대 체력 +28과 즉시 회복 46, 항성 생명핵은 중첩당 최대 체력 +12%를 적용한다.
- 성능 보호 단계는 개체 수만으로 화질을 낮추지 않는다. 측정 프레임 지연이 누적된 경우에만 효과 밀도·개체 상한을 줄이며, 해상도 축소는 심각한 지연이 추가로 2.5초 이상 지속될 때만 허용한다.

### 초월체·보스 패턴 보강

- 보스와 초월체는 플레이어가 약 1.2초 이상 거의 움직이지 않으면 현재 위치를 직접 겨냥하는 정지 대응 패턴을 사용한다.
- 시간포식자는 현재 위치와 과거 이동 기록을 겹쳐 공격하는 시간 잔상·시계바늘 절단을 사용한다.
- 종말 항성은 회전하는 안전구역이 남는 용광로 방사선과 현재·예측 위치 연속 낙성을 사용한다.
- 마지막 성좌는 전장 외곽 노드를 잇는 별자리 격자, 노드 사격과 순간이동을 사용한다.
- 세 초월체는 체력 75%·50%·25%와 전투 105초·180초·240초를 기준으로 최대 4단계까지 패턴이 확장된다.
- 전체 기본 난도는 적 체력·피해·속도를 소폭 낮췄으며, 어려움 난이도만 4분 이후 피해와 속도 보정이 시간에 따라 조금 더 빠르게 누적된다.

- 경험치 결정은 녹색 육각 결정과 십자 표식, 적 탄환은 위험색 외곽선·진행 방향 표식으로 구분한다.
