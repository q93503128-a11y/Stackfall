# STACKFALL

우주 공간에서 장비를 중첩하고 공명을 완성하며 버티는 Canvas 기반 웹 생존 액션 게임입니다.

- 저장소: `q93503128-a11y/Stackfall`
- 배포: `https://stackfall.pages.dev`
- 구성: 순수 HTML/CSS/JavaScript

## 실행

정적 웹 서버에서 루트의 `index.html`을 실행합니다.

```bash
python -m http.server 8000
```

## 현재 핵심 규칙

- 일반 장비 슬롯은 6칸이며 기본 무기 `코어 펄스`는 별도입니다.
- 일반 장비 14종은 시작 화면에서 7개씩 두 줄로 표시됩니다.
- 모든 장비는 1~6중첩마다 서로 다른 효과를 얻습니다.
- 패시브는 슬롯 제한 없이 누적되며 선택지에 실제 증가 수치가 표시됩니다.
- 치명타 확률은 최대 100%까지 적용됩니다.
- 연쇄 피해는 하드 캡 없이 증가하되 로그형 소프트 캡을 사용합니다.
- 레벨 요구 경험치는 후반으로 갈수록 이전보다 가파르게 증가합니다.
- 레벨 자체의 피해 증가는 레벨당 1.1%입니다.
- 각 무기는 별도 사거리를 사용하며, 사거리·공격 범위·관통·발동 주기를 함께 고려해 피해가 조정됩니다.
- 발동형 장비는 하단 슬롯에 실제 남은 시간과 원형 쿨다운을 표시합니다.
- 공전 장비는 보유 조합과 실제 크기에 따라 겹치지 않는 궤도를 자동 배정합니다.

## 현재 장비

기본 무기 1종과 일반 장비 14종이 구현되어 있습니다.

- 코어 펄스
- 펄스 블레이드
- 별빛 캐스터
- 성광 장벽
- 중력 우물
- 혜성 창
- 성좌 프리즘
- 시간 고리
- 성운 부메랑
- 이온 사슬
- 초신성 코일
- 유성 드론
- 성간 레일
- 은하 나선
- 반사 성좌

`성좌 프리즘`은 일반 관통 광선이 아니라 한 표적을 계속 조준할수록 세 단계로 강해지는 집속 광선입니다.

## 위협과 적

- 위협 수준은 생존 시간 1분마다 상승합니다.
- 위협이 높아질수록 일반 적의 체력·피해·이동속도가 함께 증가합니다.
- 원거리 잡몹 `성운 포격체`는 거리를 유지하며 투사체를 발사합니다.
- 중간보스나 보스가 살아 있어도 다음 정예 등장 시간이 오면 새 정예가 추가됩니다.
- 화면에는 최대 4개의 정예 체력 바가 함께 표시됩니다.
- 초월체는 일반 보스와 별도의 높은 체력·피해·스킬 빈도 계층을 사용합니다.

## 인터페이스

- `I` 또는 `Tab`으로 능력 탭을 열고 닫습니다.
- 플레이 중 능력 탭을 열어도 시간, 적 이동, 무기 발동과 렌더링이 계속됩니다.
- 레벨업·보스 보상·게임 오버 등 우선 모달이 시작되면 능력 탭은 자동으로 닫힙니다.
- 보스·중간보스·공허 보스·초월체와 각 맵 이벤트는 서로 다른 색·아이콘의 화면 가장자리 안내를 사용합니다.
- 화면 아래쪽 안내는 장비 HUD 위의 안전 영역에 배치됩니다.

## 맵 이벤트

- 성운 보관소, 추락한 우주선, 공허 균열은 독립 주기를 사용합니다.
- 모든 이벤트 종료 후 최소 58초 동안 다음 이벤트가 열리지 않습니다.
- 이벤트별 재등장 보호시간은 보상 선택이 끝난 시점부터 계산합니다.
- 같은 종류의 이벤트는 바로 연속 등장하지 않습니다.
- 우주선 이벤트가 시작되면 진입 표식은 즉시 소비되고 전투 중 다시 표시되지 않습니다.
- 우주선 이벤트 적은 일반 필드 잡몹보다 높은 체력·피해·경험치를 갖습니다.

## 안정성과 성능

- 투사체와 중력 우물은 공간 격자에서 가까운 적만 검사합니다.
- 투사체는 무기별 최대 사거리를 벗어나면 즉시 제거됩니다.
- 경험치 결정은 상한을 넘으면 값이 합쳐집니다.
- PC와 모바일은 서로 다른 동적 개체 예산을 사용합니다.
- 과부하 상태에서는 잔상, 피해 숫자, 파티클과 저우선 파편을 먼저 줄입니다.
- 재시작 전 예약된 후속 공격은 새 런에서 실행되지 않습니다.
