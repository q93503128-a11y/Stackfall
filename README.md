# STACKFALL

우주 공간에서 장비를 중첩하고 공명을 완성하며 버티는 Canvas 기반 웹 생존 액션 게임입니다.

- 저장소: `q93503128-a11y/Stackfall`
- 배포: `https://stackfall.pages.dev`
- 구성: 순수 HTML/CSS/JavaScript

## 실행

정적 웹 서버에서 루트의 `index.html`을 실행합니다.

```bash
python -m http.server 8000
```

## 현재 핵심 규칙

- 일반 장비 슬롯은 6칸입니다.
- 기본 무기 `코어 펄스`는 슬롯과 별도로 항상 존재합니다.
- 모든 장비는 1~6중첩마다 서로 다른 효과를 얻습니다.
- 패시브는 슬롯 제한 없이 누적됩니다.
- 치명타 확률은 최대 100%까지 적용됩니다.
- 연쇄 피해는 하드 캡 없이 증가하지만 증가폭이 점차 완만해집니다.
- 발동형 장비는 하단 슬롯에 실제 남은 시간과 원형 쿨다운을 표시합니다.
- 공전 장비는 보유 조합과 실제 크기에 따라 서로 겹치지 않는 별도 궤도를 자동 배정합니다.
- `광자 팽창`과 `광자 성운`의 크기 증가는 투사체뿐 아니라 광선, 중력 우물, 공전 칼날, 성운 부메랑 판정에도 적용됩니다.

## 현재 장비

기본 무기 1종과 일반 장비 14종이 구현되어 있습니다.

- 코어 펄스
- 펄스 블레이드
- 별빛 캐스터
- 성광 장벽
- 중력 우물
- 혜성 창
- 성좌 프리즘
- 시간 고리
- 성운 부메랑
- 이온 사슬
- 초신성 코일
- 유성 드론
- 성간 레일
- 은하 나선
- 반사 성좌

## 인터페이스

- `I` 또는 `Tab`으로 능력 탭을 열고 닫습니다.
- 플레이 중 능력 탭을 열어도 시간, 적 이동, 무기 발동, 투사체, 월드 이벤트와 화면 렌더링이 계속됩니다.
- 능력 탭은 별도 UI 열림 상태만 사용하며 `state.mode`를 변경하지 않습니다.
- 능력 탭의 고비용 전체 화면 블러를 제거해 Canvas가 멈춘 것처럼 보이거나 프레임이 급락하는 현상을 줄였습니다.
- 능력 탭을 연 동안 예약된 이온 사슬, 초신성, 성간 레일, 은하 나선 등의 후속 공격이 취소되지 않습니다.
- 레벨업 조건을 충족하면 능력 탭을 닫고 레벨업 선택창을 우선 표시합니다.
- 일시정지 화면에서 능력 탭을 열면 일시정지 상태는 유지됩니다.
- 능력 탭을 연 상태에서 보스 보상·메뉴 전환·게임 오버가 시작되면 탭이 자동으로 정리됩니다.
- 모바일에서는 요약을 가로로 탐색하고 장비 목록은 세로로 스크롤하며, 닫으면 조이스틱이 복구됩니다.

## 정예와 보상

- 중간보스: 청록색 표식. 처치 시 보유 장비 또는 일반 패시브가 즉시 강화됩니다.
- 일반 보스: 분홍색 표식. 처치 시 보스 특수 패시브 또는 보유 무기 특수효과 중 하나를 선택합니다.
- 공허 보스: 보라색 표식. 공허 균열 전용 보상을 제공합니다.
- 초월체: 금빛 표식. 첫 등장은 10분이며 이후 10분 간격으로 반복됩니다.

## 맵 이벤트

- 성운 보관소, 추락한 우주선, 공허 균열은 서로 다른 주기를 사용합니다.
- 이벤트 종료 시점부터 전역 최소 간격과 이벤트별 재등장 간격을 다시 계산합니다.
- 같은 이벤트가 연속으로 선택되지 않습니다.

## 안정성과 성능

- 투사체 충돌은 공간 격자로 가까운 적만 검사합니다.
- 경험치 결정은 상한을 넘으면 값이 합쳐집니다.
- 투사체·광선·파티클·충격파는 PC와 모바일의 동적 예산을 사용합니다.
- 과부하 상태에서는 잔상과 저우선 파편을 먼저 줄입니다.
- 재시작 전 예약된 후속 공격과 에코 공격은 새 런에서 실행되지 않습니다.
- 능력 탭의 열림 상태와 버튼 처리는 `src/ability-ledger-audit.js`, 단일 키보드 진입점은 `src/render.js`가 담당합니다.
- 발사체 렌더링은 누락되거나 잘못된 색상을 안전한 기본색으로 정규화합니다.

세부 규칙은 `docs/GAME_DESIGN.md`, 다음 작업 인수인계는 `docs/NEXT_CHAT_HANDOFF.md`를 참고하세요.

모든 개발 작업에서는 코드 변경과 함께 위 문서들을 실제 동작에 맞게 갱신합니다.
