# STACKFALL

장비를 중첩해 공격 방식과 우주 전장을 변화시키며 버티는 웹 생존 액션 게임입니다.

- 저장소: `q93503128-a11y/Stackfall`
- 배포: `https://stackfall.pages.dev`
- 실행 환경: 정적 HTML/CSS/JavaScript
- 게임 로직: JavaScript
- 기본 화면: Canvas 2D
- 대량 아군 투사체·전투 파티클: PixiJS WebGL
- WebGL 초기화나 CDN 로드에 실패하면 Canvas 2D로 자동 복귀

## 실행

루트 폴더에서 정적 웹 서버를 실행합니다.

```bash
python -m http.server 8000
```

그다음 브라우저에서 `http://localhost:8000`을 엽니다.

## 핵심 규칙

- 일반 장비 슬롯: 6칸
- 기본 무기 `코어 펄스`: 일반 슬롯과 별도
- 일반 장비: 14종
- 장비 중첩: 1~6
- 패시브: 슬롯 제한 없음
- 치명타 확률 상한: 100%
- 레벨당 기본 피해 증가: 1.1%
- 연쇄 피해: 하드 캡 없이 로그형 소프트 캡
- 초월체: 10분 간격
- 같은 이름의 스탯은 합연산
- 이름이 다른 피해 계수는 곱연산

## 주요 패시브 수치

- 성운 통찰: 경험치 획득량 +10%
- 개척 계약: 적 체력 +10%, 경험치 획득량 +30%
- 출력 증폭: 모든 피해 +10%
- 거성 사냥꾼: 중간보스·보스 피해 +15%
- 심우주 조준기: 무기 기본 조준·비행 사거리 +10%
- 취약점 해석: 치명타 확률 +6%
- 에코 비콘: 발사·설치형 장비 복제 확률 +7.5%

확률 증가 설명은 게임 안에서 `%`로 통일하며 `%p` 표기는 사용하지 않습니다.

## 전투 표시 고정 규칙

- 중간보스: 청록색 `◇ 중간보스`
- 일반 보스: 분홍색 `◆ 보스`
- 공허 보스: 보라색 `◉ 공허 보스`
- 초월체: 금색 `✦ 초월체`
- 화면 밖 정예는 방향·종류·거리 표시 유지
- 일반 주황 중장갑 적은 불규칙 장갑체와 용융 코어 외형을 사용
- 예전 중첩 육각형 외형으로 되돌리지 않음
- 우주선 이벤트 중장갑 적은 파손된 공성선 외형 사용

## 에코 비콘

원본 공격과 복제 공격이 완전히 겹치지 않도록 복제 공격은 약 64~91ms 뒤 발동합니다. 고중첩에서 추가 복제가 발생하면 첫 복제보다 다시 약 90~120ms 늦게 발동합니다. 복제 공격은 분홍색 계열로 구분합니다.

## 렌더링과 성능

게임 규칙·충돌·AI·보상은 기존 JavaScript 상태 배열을 그대로 사용합니다. 렌더링만 분리했습니다.

### PixiJS WebGL 담당

- 아군 투사체
- 장식용 전투 파티클
- 동일 텍스처 스프라이트 배칭
- GPU 가속 위치·회전·크기 갱신

### Canvas 2D 담당

- 배경과 성운
- 적과 보스
- 적 투사체
- 위험 예고
- 중력 우물과 특수효과
- 플레이어
- UI와 안내

PixiJS는 버전 `8.19.0`을 고정해서 불러옵니다. 로드 실패, 초기화 실패, WebGL 미지원, WebGL 컨텍스트 손실이 발생하면 게임을 중단하지 않고 기존 Canvas 2D 투사체 렌더러로 자동 복귀합니다.

기존 최적화도 유지합니다.

- 공간 해시 충돌 검사
- 유한 사거리 표적의 인접 셀 탐색
- 적 ID 색인
- 투사체 객체 풀링
- 경험치 결정 병합
- 화면 밖 개체 렌더링 생략
- 캐시된 Canvas 스프라이트
- 심한 부하에서만 최후 수단 해상도 조절

## 로딩 순서 주의

최종 렌더링 관련 순서는 반드시 아래를 유지합니다.

```text
dark-cosmic-polish.js
performance-guard.js
build-audit-ui.js
gpu-renderer.js
```

`performance-guard.js`가 적 렌더러를 교체한 뒤 `build-audit-ui.js`가 정예 종류 표시와 원거리 적 표시를 감싸야 합니다. 순서를 반대로 바꾸면 중간보스·보스 표시가 사라질 수 있습니다. `gpu-renderer.js`는 마지막에 WebGL 전투 레이어와 중장갑 적 외형 보호를 적용합니다.

세부 수치, 등장 규칙, 보상, 이벤트, 성능 원칙과 QA 항목은 `docs/GAME_DESIGN.md`를 기준으로 합니다.
