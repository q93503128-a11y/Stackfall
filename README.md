# Stackfall

우주 공간에서 장비를 중첩하고 공명을 완성하는 브라우저 생존 게임입니다.

## 실행

정적 웹 서버에서 루트의 `index.html`을 실행합니다.

```bash
python -m http.server 8000
```

## 핵심 규칙

- 장비 슬롯은 6칸입니다.
- 같은 장비를 중첩하면 2·4·6단계 공명이 개방됩니다.
- 패시브는 슬롯 제한 없이 누적됩니다.
- 자석 코어와 에코 비콘은 패시브입니다.
- 중간보스와 보스는 고유 탄막 및 예고 공격을 사용합니다.
- 장비와 패시브가 누적될수록 플레이어 코어의 외형이 변화합니다.

세부 설계 원칙은 `docs/GAME_DESIGN.md`를 참고하세요.
