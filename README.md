# Stackfall

**장비를 중첩해 공명을 완성하는 웹 생존 로그라이크.**

Muck의 런 내부 아이템 누적과 PokéRogue의 조합 확장성을, 뱀서류 실시간 생존 전투에 맞게 재구성한 프로젝트다.

## 현재 플레이 가능한 프로토타입

- Canvas 기반 실시간 생존 전투
- WASD / 방향키 / 모바일 터치 조이스틱
- 무기 슬롯 6칸
- 공격·방어·제어·성장·지원 장비
- 같은 장비 2·4·6중첩 시 전용 공명 효과
- 제한 없는 패시브 누적
- 레벨업 3지선다
- 일반·고속·탱커·정예 적
- 히트스톱, 화면 흔들림, 파티클, 피해 숫자, 체인 연출
- Web Audio API 기반 효과음
- 반응형 PC·모바일 UI

별도 빌드 과정 없이 정적 호스팅으로 실행된다. 로컬에서는 간단한 HTTP 서버 사용을 권장한다.

```bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속.

## 핵심 설계 규칙

1. **무기만 6슬롯 제한**을 둔다.
2. 무기는 직접 공격 장비일 필요가 없다.
3. 패시브는 슬롯 제한 없이 중첩된다.
4. 같은 무기 중복은 단순 수치 증가보다 행동 규칙 변화가 우선이다.
5. 6중첩은 슬롯 전부를 투자할 가치가 있을 만큼 강하고 화려해야 한다.
6. 완벽한 균형보다 빌드가 폭발하는 순간의 쾌감을 우선한다.
7. 디자인은 장식보다 판독성, 타격 피드백, 성장 체감을 우선한다.

자세한 방향은 [`docs/GAME_DESIGN.md`](docs/GAME_DESIGN.md)를 참고한다.
