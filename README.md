# STACKFALL

우주 공간에서 장비를 중첩하고 공명을 완성하며 버티는 Canvas 기반 웹 생존 액션 게임입니다.

- 저장소: `q93503128-a11y/Stackfall`
- 배포: `https://stackfall.pages.dev`
- 구성: 순수 HTML/CSS/JavaScript

## 실행

정적 웹 서버에서 루트의 `index.html`을 실행합니다.

```bash
python -m http.server 8000
```

## 현재 핵심 규칙

- 일반 장비 슬롯은 6칸이며 기본 무기 `코어 펄스`는 별도입니다.
- 일반 장비 14종은 시작 화면에서 7개씩 두 줄로 표시됩니다.
- 모든 장비는 1~6중첩마다 서로 다른 효과를 얻습니다.
- 패시브는 슬롯 제한 없이 누적되며 선택지에는 `%p` 대신 `%` 표기를 사용합니다.
- 치명타 확률은 최대 100%까지 적용됩니다.
- 연쇄 피해는 하드 캡 없이 증가하되 로그형 소프트 캡을 사용합니다.
- 레벨 요구 경험치는 후반으로 갈수록 가파르게 증가합니다.
- 레벨 자체의 피해 증가는 레벨당 1.1%입니다.
- 각 무기는 별도 기본 사거리를 사용하며 사거리·범위·관통·발동 주기를 함께 고려합니다.

## 피해 보정

- 같은 이름의 스탯은 중첩 수를 합산해 하나의 계수를 만듭니다.
- 서로 다른 이름의 피해 계수는 기본적으로 서로 곱합니다.
- `출력 증폭`: 모든 적에게 중첩당 피해 +10%.
- `거성 사냥꾼`: 중간보스·보스에게 중첩당 피해 +15%.
- 출력 증폭 1중첩과 거성 사냥꾼 1중첩을 함께 보유하면 보스 대상 배율은 `1.10 × 1.15 = 1.265`입니다.
- 레벨, 성운 강화, 초월체 유산, 공허 각인, 연쇄와 체력 조건부 피해도 각각 별도 계층으로 적용됩니다.

## 경험치·사거리 패시브

- `성운 통찰`: 아무 불이익 없이 경험치 획득량 +10%.
- `개척 계약`: 적 체력 +10%, 경험치 획득량 +30%.
- 경험치 획득량이라는 같은 스탯끼리는 합산합니다.
- `심우주 조준기`: 무기의 기본 조준·비행 사거리 +10%.
- 심우주 조준기는 코어 펄스, 원거리 투사체, 프리즘, 드론, 레일, 부메랑 등 `weaponRange()`를 사용하는 공격에 적용됩니다.

## 성좌 프리즘

성좌 프리즘은 한 표적을 계속 조준할수록 강해지는 3단계 집속 광선입니다.

- 기본 출력: ×1
- 용광 단계: ×1.9
- 소각 단계: ×4.1
- 5중첩 최대 출력: ×4.35
- 6중첩 최대 출력: ×4.6
- 4중첩부터 집속 전환 시간이 단축됩니다.
- 6중첩에서는 프리즘 3개가 서로 다른 표적을 조준합니다.
- 보스 특수효과 `과열 성선`은 최대 출력 유지 중 표적을 중심으로 교차 광선과 용광 폭발을 발생시킵니다.

## 위협과 적

- 위협 수준은 생존 시간 1분마다 상승합니다.
- 위협이 높아질수록 일반 적의 체력·피해·이동속도가 함께 증가합니다.
- 원거리 잡몹 `성운 포격체`는 거리를 유지하며 투사체를 발사합니다.
- 중간보스나 보스가 살아 있어도 다음 정예 등장 시간이 오면 새 정예가 추가됩니다.
- 화면에는 최대 4개의 정예 체력 바가 함께 표시됩니다.
- 일반 보스 체력은 기존 대비 약 12%, 공허 보스는 약 8% 낮췄습니다.
- 초월체 체력과 공격 빈도는 일반 보스보다 훨씬 높게 유지됩니다.

## 인터페이스

- `I` 또는 `Tab`으로 능력 탭을 열고 닫습니다.
- 레벨업·보스 보상·게임 오버 등 우선 모달이 시작되면 능력 탭은 자동으로 닫힙니다.
- 보스·중간보스·공허 보스·초월체와 각 맵 이벤트는 서로 다른 색·아이콘의 안내를 사용합니다.
- 화면 아래쪽 안내는 장비 HUD 위의 안전 영역에 배치됩니다.
- 설정의 `아군 투사체 숨기기`는 적 탄환과 위험 예고는 남기고 아군 탄환·광선·곡선·전투 파티클 렌더링을 숨깁니다.

## 맵 이벤트

- 성운 보관소, 추락한 우주선, 공허 균열은 독립 주기를 사용합니다.
- 모든 이벤트 종료 후 최소 58초 동안 다음 이벤트가 열리지 않습니다.
- 이벤트별 재등장 보호시간은 보상 선택이 끝난 시점부터 계산합니다.
- 같은 종류의 이벤트는 바로 연속 등장하지 않습니다.
- 우주선 이벤트가 시작되면 진입 표식은 즉시 소비되고 전투 중 다시 표시되지 않습니다.

## 안정성과 성능

- 투사체와 중력 우물은 공간 격자에서 가까운 적만 검사합니다.
- 유한 사거리 표적 탐색도 공간 격자를 사용해 매 공격마다 전체 적 배열을 훑지 않습니다.
- 적 ID 색인을 만들어 부메랑 등 추적 무기가 매 프레임 전체 적을 검색하지 않습니다.
- 투사체 객체를 재사용하는 풀을 두어 장시간 런의 메모리 할당과 가비지 컬렉션 부담을 줄입니다.
- 투사체와 일반 적의 복잡한 벡터 그림은 OffscreenCanvas에 한 번 그린 뒤 캐시된 스프라이트로 재사용합니다.
- 프리즘 광선 잔상 생성 간격은 부하 상태에서 자동으로 완화됩니다.
- 투사체는 무기별 최대 사거리를 벗어나면 즉시 제거됩니다.
- 경험치 결정은 상한을 넘으면 값이 합쳐집니다.
- 실제 프레임 시간과 현재 개체 수를 함께 측정하지만 품질 저하는 심한 과부하에서만 최후 수단으로 적용합니다.
- 고해상도 기기에서도 기본 DPR 상한을 데스크톱 1.75, 모바일 1.35로 제한합니다.
- 심한 프레임 저하가 1.8초 이상 이어질 때만 Canvas 내부 해상도를 80%로 낮추며, 안정 상태가 7초 이어지면 원복합니다.
- 재시작 전 예약된 후속 공격은 새 런에서 실행되지 않습니다.
