## 5. 피해 보정 원칙

- 같은 이름의 스탯은 중첩 수를 합산해 한 계수를 만든다.
- 이름이 다른 피해 계수는 기본적으로 곱한다.
- 같은 스탯 중첩을 중첩마다 복리식으로 다시 곱하지 않는다.

### 출력 증폭

```text
모든 피해 계수 = 1 + 출력 증폭 중첩 × 0.16
```

### 거성 사냥꾼

```text
정예 피해 계수 = 1 + 거성 사냥꾼 중첩 × 0.10
```

### 동시 보유 예시

```text
출력 증폭 1중첩 + 거성 사냥꾼 1중첩
보스 대상 배율 = 1.16 × 1.10 = 1.276
```

`progression-expansion.js`에는 과거 정예 피해 `×1.12` 래퍼가 남아 있다. 마지막에 로드되는 `performance-guard.js`가 옛 계수를 제거하고 최종 `×1.10` 계수로 치환한다. 이 부분을 수정할 때 중복 적용을 반드시 확인한다.

## 6. 경험치 패시브

- 성운 통찰: 경험치 +8%
- 개척 계약: 적 체력 +5%, 경험치 +14%
- 두 효과는 같은 `경험치 획득량` 스탯이므로 합산한다.

최종 경험치 계산:

```text
1 + 개척 계약 중첩 × 0.14 + 성운 통찰 중첩 × 0.08
```

적 체력 보정:

```text
기본 시간 성장 × (1 + 개척 계약 중첩 × 0.05)
```

## 7. 정예 체력

- 중간보스: 기존 수치 유지
- 일반 보스: 기존 최종 체력 ×0.88
- 공허 보스: 기존 최종 체력 ×0.92
- 초월체: 체력 너프 미적용

초월체는 일반 보스보다 훨씬 강한 계층을 유지한다.

## 8. 레벨과 위협

레벨 요구 경험치:

```text
10 + 3.8 × level + 1.35 × level^1.34
```

- 레벨당 피해 +1.1%
- 위협은 1분마다 상승
- 위협 상승 시 적 체력·피해·이동속도·원거리 공격 빈도 증가
- 개체 수만 늘리지 않고 적 스탯으로 난도를 높인다.

## 10. 정예 등장과 보상

- 순환: 중간보스 → 중간보스 → 보스
- 기존 정예가 살아 있어도 다음 정예 시간에 추가 등장
- 동시 정예 4명부터 다음 등장 연기
- 초월체 직전 일반 정예 신규 등장 중단

보상:

- 중간보스: 보유 장비 +1 또는 일반 패시브 +1
- 일반 보스: 특수 패시브 또는 무기 특수효과
- 공허 보스: 공허 전용 보상
- 초월체: 고유 유산

## 11. 이벤트

- 이벤트 종료 후 최소 58초 간격
- 같은 유형 연속 등장 금지
- 주기는 보상 선택 완료 시점부터 재계산
- 우주선 이벤트 진입 즉시 포탈 표식 소비
- 이벤트 활성 중 새 표식 생성 금지

## 12. 성능 병목

현재 가장 큰 비용은 단순 개체 수만이 아니다.

- 투사체마다 그라디언트, 그림자, 궤적과 `save/restore`를 개별 실행
- 배경의 전면 그라디언트, 성운 그라디언트와 별을 매 프레임 다시 그림
- 광선, 부메랑 곡선, 파티클, 피해 숫자와 보스 표시가 메인 스레드에서 동시에 실행
- Canvas 2D는 성숙한 게임 엔진의 스프라이트 배칭과 동일한 구조가 아님
- 고해상도 디스플레이에서는 픽셀 채우기 비용이 크게 증가

## 13. 프레임 적응형 성능 구조

`performance-guard.js`는 실제 프레임 시간과 개체 압력을 함께 본다.

### 품질 0: 정상

- 전체 배경·적·투사체 비주얼 유지
- 원래 Canvas 내부 해상도 사용

### 품질 1: 감소

- 적·투사체·광선·파티클 상한 축소
- 성운 배경 제거, 별 밀도 감소
- 아군·적 투사체를 단순 선과 원으로 렌더링
- 그림자와 블랙홀 효과 축소
- Canvas 내부 해상도 82%

### 품질 2: 긴급

- 일반 적 단순 도형 렌더링
- 배경을 단색과 소수 별로 단순화
- 아군·적 투사체 최소 렌더링
- 블랙홀 단순 렌더링
- 광선·곡선·파티클 최소화
- Canvas 내부 해상도 68%

해상도는 부하가 생기면 빠르게 낮추고, 프레임이 충분히 안정된 상태가 5초 이상 유지된 뒤 한 단계씩 복구한다.

기본 DPR 상한:

- 데스크톱: 1.75
- 모바일: 1.35

## 14. 아군 투사체 숨기기

설정의 `아군 투사체 숨기기`는 최후 수단이다.

- 실제 공격, 충돌, 피해 계산은 유지
- 아군 탄환 렌더링 중단
- 광선, 부메랑 곡선, 전투 파티클을 최소 효과 렌더러로 교체
- 적 탄환은 계속 표시
- 보스 장판과 위험 예고는 계속 표시
- 설정값은 `localStorage`의 `stackfall.settings.hideProjectiles`에 저장

## 15. 능력 탭

- `I` 또는 `Tab`으로 열고 닫기
- 레벨업·보상·게임 오버가 우선
- 실제 배포본에서 타이머, 적 이동, 무기 발동이 계속되는지 반드시 확인

능력 탭은 과거 여러 파일의 상태 재대입 충돌이 반복된 영역이다. `state.mode`, DOM 표시 상태, 입력 리스너를 함께 검사한다.
