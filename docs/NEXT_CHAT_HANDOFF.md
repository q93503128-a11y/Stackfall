## 핵심 밸런스

- 출력 증폭: 모든 피해 +10%
- 거성 사냥꾼: 중간보스·보스 피해 +15%
- 서로 다른 피해 계수는 곱연산
- 같은 이름의 스탯 중첩은 합연산
- 성운 통찰: 경험치 +10%
- 개척 계약: 적 체력 +10%, 경험치 +30%
- 경험치 증가끼리는 합연산
- 레벨당 기본 피해 +1.1%

## 심우주 조준기

- 신규 패시브 키: `range`
- 이름: 심우주 조준기
- 중첩당 기본 조준·비행 사거리 +10%
- 최대 6중첩
- 최종 `weaponRange(key)`가 기본 사거리에 `1 + range 중첩 × 0.10`을 곱한다.
- 코어, 별빛 캐스터, 혜성 창, 프리즘, 부메랑, 이온 사슬, 드론, 레일, 나선, 반사 성좌 등 `weaponRange()` 기반 장비에 적용된다.
- 펄스 블레이드 공전 궤도처럼 별도 구조를 사용하는 공격에는 적용되지 않는다.

## 성좌 프리즘 최종 규칙

- 기본 사거리: 520, 심우주 조준기 적용
- 1중첩: 프리즘 1개, ×1
- 2중첩: 프리즘 2개, 별도 표적
- 3중첩: 0.88초 후 ×1.9, 2.18초 후 ×4.1
- 4중첩: 0.68초 후 ×1.9, 1.78초 후 ×4.1
- 5중첩: 최대 출력 ×4.35, 광선 굵기 증가
- 6중첩: 프리즘 3개, 최대 출력 ×4.6, 최종 집속 1.55초
- 표적 사망·사거리 이탈 시 해당 프리즘 열 초기화
- 에코 비콘 복제는 현재 프리즘 위치에서 순간 광선 발사

### 프리즘 보스 특수효과

- 최종 표시 이름: `과열 성선`
- 최대 출력 유지 중 약 1.15초마다 발동
- 표적을 중심으로 주 광선과 수직인 교차 광선 생성
- 교차 광선 경로 추가 피해
- 표적 중심 소형 용광 폭발
- 기존 `교차 성선` 문구는 보상 카드와 능력 탭에서 새 이름으로 동기화한다.

## 선택지와 능력 탭

- 에코 비콘: `+7.5%`
- 취약점 해석: `+6%`
- `%p` 표기 금지
- 능력 탭 정예 피해는 중첩당 15%로 표시
- 능력 탭에 무기 사거리 증가량 표시
- 장비 상세 카드의 프리즘 최대 출력은 5중첩 ×4.35, 6중첩 ×4.6

## 성능 구조

- 공간 해시 격자로 투사체·중력 우물 충돌 검사
- 유한 사거리 표적 탐색은 인접 셀만 검사
- 적 ID 색인으로 부메랑 목표 반복 탐색 감소
- 투사체 객체 풀 사용
- 일반 적과 투사체는 OffscreenCanvas 캐시 스프라이트 사용
- 화면 밖 개체 렌더링 생략
- 경험치 결정 병합
- 성좌 프리즘 광선 시각 객체는 정상 상태 약 0.075초, 부하 상태 약 0.11초 간격으로 생성
- 피해 틱은 0.18초 유지
- 품질 저하는 심한 과부하에서만 마지막 안전장치로 사용

## WebGL·PixiJS 이관

- 새 저장소가 필요하지 않다.
- 같은 GitHub 저장소와 Cloudflare Pages 주소를 유지할 수 있다.
- 게임 규칙·AI·충돌·보상·저장은 유지하고 렌더링 계층만 교체한다.
- 권장 순서: 아군 투사체·파티클 → 일반 적·배경 → 광선·중력 우물 → 보스 효과

- 사용자가 직접 코드를 작성할 필요는 없다. 다만 실제 배포본의 조작감과 비주얼 확인은 사용자 검수가 필요하다.
