## 2. 매 작업의 절대 원칙

1. `README.md`, `docs/GAME_DESIGN.md`, 이 문서를 먼저 읽는다.
2. 배포본에서 재현 가능한 문제를 먼저 확인한다.
3. `index.html` 로딩 순서를 따라 최종 실행 함수를 찾는다.
4. 가능한 한 기존 원본 모듈을 직접 수정한다.
5. 새 fix/override 파일을 계속 추가하지 않는다.
6. 인게임에 패치 내역, 개발 설명, 계산식 TMI를 넣지 않는다.
7. 선택지 설명은 짧고 실제 효과와 정확히 일치시킨다.
8. 우주적이고 광활하며 심오한 분위기와 타격감을 우선한다.
9. 장시간 런에서 적, 투사체, 광선, 파티클, 경험치가 누적되지 않게 한다.
10. 코드 변경이 끝나면 `README.md`, `docs/GAME_DESIGN.md`, `docs/NEXT_CHAT_HANDOFF.md`도 실제 코드에 맞게 갱신한다.
11. JavaScript 문법, 브라우저 콘솔, 데스크톱·모바일 플레이를 확인한다.
12. 확인하지 못한 항목을 확인했다고 말하지 않는다.

## 4. 핵심 게임 규칙

- 장르: Vampire Survivors 계열의 자동 공격 생존 액션
- 일반 장비 슬롯: 6칸
- 기본 무기 `코어 펄스`: 일반 슬롯과 별도
- 모든 장비: 1~6중첩 효과
- 패시브: 슬롯 제한 없음
- 치명타 확률: 최대 100%
- 연쇄 피해: 하드 캡 없음, 로그형 소프트 캡
- 초월체: 10분마다 등장
- 같은 맵 이벤트는 연속 등장하지 않음

   - 에코 복제는 붉은 강착 원반

5. 혜성 창
   - 긴 창 형태의 관통 투사체

   - 크기 증가는 광선 굵기와 판정에 적용

7. 시간 고리
   - 주변 감속
   - 고중첩 시간 파동과 장비 가속

9. 이온 사슬

    - 서로 다른 표적 자동 사격

## 6. 크기 증가 규칙

`광자 팽창`과 성운 보관소의 `광자 성운`은 다음에 적용한다.

- 일반 투사체 반경
- 성좌 프리즘 광선 굵기와 접촉 판정
- 중력 우물 반경
- 펄스 블레이드 판정
- 성운 부메랑 판정
- 시간 고리 파동 반경

인게임 선택지에는 기능만 간결하게 설명한다. 최대 중첩, 캡, 내부 계산식은 적지 않는다.

## 7. 연쇄 시스템

- 연쇄가 높을수록 피해 증가
- 하드 캡 없음
- 로그형 소프트 캡으로 증가폭 감소
- 연쇄 추진기: 연쇄가 높을수록 장비 주기 단축
- 연쇄 폭심: 일정 연쇄마다 플레이어 중심 폭발
- 연쇄 회수: 일정 연쇄마다 체력 회복
- 전리품 공명: 연쇄가 높을수록 자석 범위 증가

선택지에서 최대 중첩, 200연쇄, 캡 같은 문구를 표시하지 않는다.

## 10. 맵 이벤트

### 공통

- 동시에 하나만 활성화
- 이벤트 종료 후 최소 48초 동안 다음 이벤트 없음
- 이벤트별 재등장 보호시간은 보상 선택 완료 시점부터 계산
- 같은 이벤트는 바로 연속 등장하지 않음
- 이벤트 표식은 접근 전까지 유지
- 추락한 우주선 전투장 테두리는 이벤트 종료 후 사라지는 것이 정상

### 성운 보관소

- 첫 등장 약 42초
- 기본 반복 55~78초
- 같은 유형 보호시간 95초
- 전투 없이 강화 선택

### 추락한 우주선

- 첫 등장 약 78초
- 기본 반복 95~135초
- 같은 유형 보호시간 155초
- 격리 전장 3웨이브
- 보상:
  - 무작위 패시브 2종 +1
  - 무작위 보유 무기 +2
  - 최대 체력 증가와 회복
  - 자동 보호막 강화

### 공허 균열

- 첫 등장 약 132초
- 기본 반복 170~230초
- 같은 유형 보호시간 230초
- 전용 공허 보스
- 보상:
  - 보유 무기 전체 +1
  - 무작위 패시브 3종 +1
  - 공허 각인

## 12. 블랙홀과 특이점

- 일반 중력 우물은 블랙홀 형태
- 사건의 지평선, 백색 광자 고리, 강착 원반
- 강착 원반 면은 고정
- 원반 안의 입자와 물질 조각이 빠르게 회전
- 에코 복제 우물은 붉은색
- 특이점 혈맥은 자홍색 각진 붕괴별

## 13. 사운드

- 전체 출력은 설정 50%, 시스템 음량 30에서도 들리는 수준을 목표
- 배경음은 평화로운 멜로디보다 어둡고 무겁고 신비한 저음 중심
- 전투 효과음, UI 효과음, 배경음은 개별 채널
- 보스 공격과 레벨업은 저음과 잔향을 포함한 다층 효과음
- 컴프레서로 큰 소리의 찢어짐 방지

## 14. 성능 구조

- 숫자형 공간 해시 격자
- 투사체와 우물은 인접 적만 검사
- 배열 제자리 압축
- 경험치 결정 압축
- 저우선 파편 우선 제거
- PC·모바일별 개체 예산
- 과부하 시 잔상과 파티클 감소
- 유성 드론 방사탄, 혜성 파편, 별가루는 저우선 제거 대상
- 블랙홀 입자 수는 부하 상태에서 감소

Vampire Survivors처럼 수많은 적을 처리하려면 충돌 검사와 메모리 할당을 먼저 줄이고, 그다음 발광과 파티클을 동적 예산으로 관리한다.

## 15. 능력 탭

- `I` 또는 `Tab`
- 현재 장비와 패시브 표시
- 장비 카드 클릭 시 1~6중첩 효과와 현재 수치 표시
- 패시브 카드 클릭 시 현재 효과 표시
- 상한 정보 버튼 없음
- 최대 중첩과 내부 캡을 선택지에 표시하지 않음
- 왼쪽 패시브 HUD는 세로 스크롤 가능

## 16. 현재 주의할 구조적 위험

- 후반 파일의 함수 재대입이 많다.
- `firePrism`, `createGravityWells`, `updateWeapons`, `drawPlayer`, `drawWells`, `drawEnemies`, `killEnemy`는 여러 파일에서 감싸진다.
- 새 기능을 넣을 때 최종 함수가 실제로 호출되는지 로딩 순서로 검증한다.
- 장비 크기 증가는 원본 투사체와 후반 보정 광선·우물 양쪽에서 중복 적용되지 않게 `attackSizeScaled` 표식을 사용한다.
- 보상 큐는 중간보스, 공허 보스, 초월체에서 중복 보상이 발생하지 않게 확인한다.
- 이벤트 타이머는 이벤트 시작이 아니라 종료·선택 완료 시점의 보호시간도 확인한다.

## 17. 수정 후 QA

### 기본

- 게임 시작
- 시작 장비 11종 모두 선택 가능
- 코어 펄스는 시작 장비 목록에 노출되지 않음
- 레벨업 선택지 3장 유지
- 하단 장비 HUD 동기화
- 능력 탭 열기와 닫기

### 신규 장비

- 이온 사슬의 연결, 분기, 이중 방전
- 초신성 코일의 후속 파동과 밀치기
- 유성 드론 수, 교차 사격, 방사 사격
- 에코 비콘 복제
- 크기 패시브 적용

### 이벤트

- 우주선 이벤트 종료 직후 같은 우주선 표식이 다시 생기지 않음
- 보상 선택 후 48초 이전에 다른 이벤트가 생기지 않음
- 같은 이벤트가 연속 등장하지 않음
- 우주선 전장 테두리가 종료 후 제거됨

### 정예 보상

- 중간보스는 즉시 일반 강화만 제공
- 일반 보스는 특수 보상 선택창 제공
- 공허 보스와 초월체는 일반 보스 보상 미제공

### 성능

- 10분 이상 플레이
- 투사체·광선·파티클 상한 유지
- 경험치 결정 압축
- 모바일에서 프레임 급락 여부
- 브라우저 콘솔 오류 여부

## 18. 현재 가장 최근 변경

- 이벤트 전역 최소 간격과 유형별 보호시간을 종료 시점 기준으로 재구성
- 중간보스와 일반 보스 보상 단계 분리
- 투사체 크기 증가를 광선, 중력 우물, 칼날, 부메랑, 시간 파동에 확대
- 블랙홀 강착 원반 입자 회전 강화
- 신규 장비 `이온 사슬`, `초신성 코일`, `유성 드론` 추가
- 시작 장비 목록 자동 줄바꿈·스크롤 적용
- 문서 3종을 현재 코드와 동기화
