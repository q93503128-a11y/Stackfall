# STACKFALL 게임·비주얼 설계 기준

마지막 동기화: 2026-07-15

## 한 문장 정의

> 여섯 개의 일반 장비 슬롯과 별도 기본 무기를 중첩해, 화면과 전투 규칙이 실제로 변하는 빌드를 만드는 우주 생존 액션 게임.

## 절대 개발 원칙

- 이미지를 생성하거나 외부 이미지 파일을 추가하지 않는다.
- 가능한 한 기존 원본 모듈을 직접 수정한다.
- `index.html`의 스크립트 로딩 순서를 기준으로 최종 실행 함수를 추적한다.
- 인게임에 패치 내역, 개발 설명, 계산식 TMI를 넣지 않는다.
- 선택지 설명은 짧고 실제 효과와 일치해야 한다.
- 코드 변경 시 `README.md`, 이 문서, `docs/NEXT_CHAT_HANDOFF.md`를 함께 갱신한다.
- 장시간 런의 개체 누적, 충돌 계산, DOM 갱신 비용을 항상 확인한다.

## 핵심 규칙

- 일반 장비 슬롯: 6칸
- 기본 무기 `코어 펄스`: 일반 슬롯과 별도
- 장비: 1~6중첩마다 효과 존재
- 패시브: 슬롯 제한 없음
- 치명타 확률: 최대 100%
- 연쇄 피해: 하드 캡 없음, 로그형 소프트 캡
- 공격 주기: 여러 가속 효과를 합산하되 최종 하한 존재
- 초월체: 10분, 20분, 30분 순서로 등장

## 성장의 가시성

장비와 패시브가 숫자로만 강해져서는 안 된다.

- 투사체 수와 크기
- 광선 굵기
- 중력 우물 반경
- 공전 칼날 판정
- 궤적과 잔상
- 충격파와 화면 흔들림
- 플레이어 코어 외형

`광자 팽창`과 `광자 성운`의 크기 증가는 다음에 공통 적용한다.

- 일반 투사체
- 성좌 프리즘 광선
- 중력 우물
- 펄스 블레이드 판정
- 성운 부메랑 판정
- 시간 고리 파동

## 패시브 설명 원칙

선택지에는 기능만 설명한다.

좋은 예:

- `현재 연쇄가 높을수록 장비 발동 주기 단축.`
- `결정 흡수 범위 증가.`
- `투사체·광선·중력 우물·공전 칼날 크기 증가.`

표시하지 않는 내용:

- 최대 중첩 수
- 하드 캡
- 내부 계산식
- 특정 수치 이후의 내부 소프트 캡
- 개발 과정과 패치 사유

세부 수치는 능력 상세 카드에서 현재 적용값 중심으로만 보여준다.

## 연쇄 시스템

- 연쇄가 높을수록 기본 피해 보너스가 증가한다.
- 하드 캡 대신 증가폭이 점차 줄어드는 소프트 캡을 사용한다.
- 연쇄 추진기: 연쇄가 높을수록 장비 발동 주기 단축
- 연쇄 폭심: 일정 연쇄마다 플레이어 중심 폭발
- 연쇄 회수: 일정 연쇄마다 체력 회복
- 전리품 공명: 연쇄가 높을수록 자석 범위 증가

## 정예 구분과 보상

### 중간보스

- 청록색 마름모 표식과 `중간보스` 라벨
- 일반 보스보다 낮은 체력과 보상
- 처치 시 보유 장비 1중첩 또는 일반 패시브 1중첩을 즉시 획득
- 보스 특수 패시브 선택창은 열지 않음

### 일반 보스

- 분홍색 대형 회전 고리와 `보스` 라벨
- 처치 시 3개의 보스 보상 중 하나 선택
- 보상 종류:
  - 보스 특수 패시브
  - 현재 보유 무기 특수효과

### 공허 보스

- 보라색 표식과 `공허 보스` 라벨
- 일반 보스 보상과 중복되지 않는 공허 전용 보상

### 초월체

- 금빛 표식과 `초월체` 라벨
- 독립 등장 장면과 전용 유산 보상
- 첫 등장 10분, 이후 10분 간격

## 맵 이벤트

### 공통 규칙

- 동시에 하나의 이벤트만 활성화한다.
- 이벤트 표식은 접근하기 전까지 유지한다.
- 이벤트 전투장과 입구 연출은 이벤트 종료 후 제거된다.
- 이벤트 재등장 간격은 이벤트 시작이 아니라 보상 선택이 끝난 시점부터 다시 계산한다.
- 모든 이벤트 종료 후 최소 48초 동안 다음 이벤트를 열지 않는다.
- 같은 이벤트는 바로 연속해서 선택하지 않는다.

### 성운 보관소

- 첫 등장 약 42초
- 기본 반복 주기 55~78초
- 같은 성운 보관소의 재등장 보호시간 95초
- 전투 없이 성운 강화 3개 중 하나 선택

### 추락한 우주선

- 첫 등장 약 78초
- 기본 반복 주기 95~135초
- 같은 우주선 이벤트의 재등장 보호시간 155초
- 격리 전장 안에서 강화 잡몹 3웨이브
- 전장은 보상 선택 단계에서 제거됨

### 공허 균열

- 첫 등장 약 132초
- 기본 반복 주기 170~230초
- 같은 공허 균열의 재등장 보호시간 230초
- 전용 차원 전환과 공허 보스

## 블랙홀과 특이점

- 중력 우물은 검은 사건의 지평선과 강착 원반을 사용한다.
- 강착 원반 자체가 원자 궤도처럼 기울어 회전하지 않는다.
- 원반 면은 유지하고 빛나는 입자와 물질 조각이 빠르게 흐른다.
- 에코 비콘 복제 우물은 붉은 강착 원반으로 표시한다.
- 특이점 혈맥은 자홍색 각진 붕괴별로 구분한다.

## 성능 구조

- 적을 숫자형 공간 해시 격자에 배치한다.
- 투사체와 중력 우물은 인접 격자의 적만 검사한다.
- 배열 정리는 매 프레임 새 배열을 만들지 않고 제자리 압축한다.
- 저우선 투사체와 파편을 먼저 제거한다.
- PC와 모바일은 별도의 개체 예산을 사용한다.
- 부하가 높으면 잔상, 파티클, 파편 수를 자동으로 줄인다.
- 경험치 결정은 상한을 넘으면 값을 합친다.

## 비주얼 우선순위

1. 위험과 적 종류가 즉시 구분되는가
2. 공격 적중과 보스 공격 발동이 강하게 느껴지는가
3. 장비 중첩 전후가 보이는가
4. UI가 전투 시야를 가리지 않는가
5. 장식이 우주적 분위기를 보강하는가

## 금지 사항

- 모든 장비를 피해량 증가의 다른 표현으로 만드는 것
- 장비 6중첩을 단순 배수 증가로 끝내는 것
- 선택지에 최대 중첩과 내부 캡을 노출하는 것
- 화면을 가리는 불투명 UI
- 경고 장판과 실제 판정이 다른 것
- 성능 문제를 파티클 전체 삭제만으로 해결하는 것
- 새 fix/override 파일을 계속 추가하는 것
