# STACKFALL 게임·비주얼 설계 기준

마지막 동기화: 2026-07-15

## 한 문장 정의

> 여섯 개의 일반 장비 슬롯과 별도 기본 무기를 중첩해, 화면과 전투 규칙이 실제로 변하는 빌드를 만드는 우주 생존 액션 게임.

## 절대 개발 원칙

- 이미지를 생성하거나 외부 이미지 파일을 추가하지 않는다.
- 가능한 한 기존 원본 모듈을 직접 수정한다.
- `index.html`의 스크립트 로딩 순서를 기준으로 최종 실행 함수를 추적한다.
- 인게임에 패치 내역, 개발 설명, 계산식 TMI를 넣지 않는다.
- 선택지 설명은 짧고 실제 효과와 일치해야 한다.
- 코드 변경 시 `README.md`, 이 문서, `docs/NEXT_CHAT_HANDOFF.md`를 함께 갱신한다.
- 장시간 런의 개체 누적, 충돌 계산, DOM 갱신 비용을 항상 확인한다.
- 재시작 이전에 예약된 지연 공격이 새 런에 침범하지 않도록 런 식별자를 사용한다.

## 핵심 규칙

- 일반 장비 슬롯: 6칸
- 기본 무기 `코어 펄스`: 일반 슬롯과 별도
- 장비: 1~6중첩마다 효과 존재
- 패시브: 슬롯 제한 없음
- 치명타 확률: 최대 100%
- 연쇄 피해: 하드 캡 없음, 로그형 소프트 캡
- 공격 주기: 여러 가속 효과를 합산하되 최종 하한 존재
- 초월체: 10분, 20분, 30분 순서로 등장
- 발동형 장비: 실제 남은 시간과 쿨다운 원형 표시
- 지속형 장비: 거짓 쿨다운 표시 금지

## 성장의 가시성

장비와 패시브가 숫자로만 강해져서는 안 된다.

- 투사체 수와 크기
- 광선 굵기와 개수
- 중력 우물 반경
- 공전 칼날 판정
- 궤적과 잔상
- 충격파와 화면 흔들림
- 플레이어 코어 외형
- 방어 장비의 보호막과 반사 연출

`광자 팽창`과 `광자 성운`의 크기 증가는 다음에 공통 적용한다.

- 일반 투사체
- 성좌 프리즘 광선
- 성간 레일 광선
- 중력 우물
- 펄스 블레이드 판정과 외형
- 성운 부메랑 판정
- 시간 고리 파동
- 초신성 코일 파동
- 반사 성좌 반사장

## 공전 장비 궤도 규칙

공전 장비가 서로 겹치면 장비를 식별하기 어렵고 실제 충돌 판정과 외형도 어긋난다.

- 공전 장비 순서: 성광 장벽 → 펄스 블레이드 → 성좌 프리즘 → 유성 드론
- 현재 보유한 공전 장비만 계산한다.
- 각 장비의 실제 반지름과 크기 배율을 바탕으로 다음 궤도를 바깥쪽에 배정한다.
- 장비가 추가되거나 크기 패시브가 변하면 궤도도 자동으로 다시 계산한다.
- 펄스 블레이드의 실제 충돌 반경과 화면상 궤도는 동일한 함수를 사용한다.
- 성좌 프리즘과 유성 드론의 발사 위치도 화면상 궤도와 동일해야 한다.

## 신규 장비 세부 정체성

### 성간 레일

- 가장 가까운 적 방향으로 화면을 가로지르는 즉발 관통 광선
- 중첩에 따라 굵기, 평행 광선, 후속 잔광, 정예 추가 피해가 열린다.
- 6중첩은 표적을 중심으로 수직 교차 광선을 추가한다.
- 일반 탄환 무기처럼 보이지 않도록 짧고 강한 광선 연출을 사용한다.

### 은하 나선

- 여러 갈래의 탄환이 시간차를 두고 회전 방향으로 퍼진다.
- 3중첩부터 가까운 적을 완만하게 추적한다.
- 중첩이 늘수록 나선 팔과 한 번에 방출하는 탄환 묶음이 증가한다.
- 과부하 시 저우선 탄환부터 제거할 수 있다.

### 반사 성좌

- 일정 반경 안의 적 투사체를 제거하고 아군 광탄으로 되돌린다.
- 반사할 탄환이 없을 때에도 고중첩에서는 가까운 적에게 반격탄을 발사한다.
- 5중첩부터 보호막을 충전한다.
- 6중첩은 넓은 반사장과 중심 반격 파동을 만든다.

## 쿨다운 HUD 규칙

- 하단 슬롯의 원형 진행도는 장비의 실제 내부 쿨다운 변수를 읽는다.
- 표시 최대 시간은 실제 `hasteMult()`가 반영된 발동 주기와 같아야 한다.
- 이온 사슬, 초신성 코일, 유성 드론, 성간 레일, 은하 나선, 반사 성좌도 기존 장비와 동일하게 표시한다.
- 쿨다운이 없는 펄스 블레이드는 진행 원형을 표시하지 않는다.
- 보호막 기능이 열리기 전의 성광 장벽과 공격 기능이 열리기 전의 시간 고리는 빈 쿨다운을 표시한다.
- 재시작 시 모든 쿨다운과 발사 카운터를 초기화한다.

## 능력 탭 규칙

- `I` 또는 `Tab`으로 연다.
- 능력 탭은 자체 `ledgerOpen` UI 상태만 소유하며 `state.mode`를 변경하지 않는다.
- 탭을 연 순간 기존 이동 입력을 비워 의도치 않은 계속 이동을 막는다.
- 플레이 중에는 전투가 계속되고, 일시정지 화면에서 열면 일시정지 상태를 유지한다.
- `I`, `Tab`, `Escape`는 `render.js`의 캡처 단계 단일 진입점에서 처리한다.
- 레벨업, 보스 보상, 월드 이벤트, 메뉴 전환이 시작되면 열린 탭을 자동으로 닫는다.
- 재시작 후 내부 열림 상태가 남지 않아야 한다.
- DOM 변경 감시기로 렌더 후 처리를 반복하지 않고, 명시적인 `stackfall:ledger-rendered` 이벤트로 상세 카드를 연결한다.
- 모바일에서는 shell이 안전 영역 안에 들어와야 하며, 요약은 가로 스크롤, 능력 목록은 세로 스크롤을 사용한다.

## 패시브 설명 원칙

선택지에는 기능만 설명한다.

좋은 예:

- `현재 연쇄가 높을수록 장비 발동 주기 단축.`
- `결정 흡수 범위 증가.`
- `투사체·광선·중력 우물·공전 칼날 크기 증가.`

표시하지 않는 내용:

- 최대 중첩 수
- 하드 캡
- 내부 계산식
- 특정 수치 이후의 내부 소프트 캡
- 개발 과정과 패치 사유

세부 수치는 능력 상세 카드에서 현재 적용값 중심으로만 보여준다.

## 연쇄 시스템

- 연쇄가 높을수록 기본 피해 보너스가 증가한다.
- 하드 캡 대신 증가폭이 점차 줄어드는 소프트 캡을 사용한다.
- 연쇄 추진기: 연쇄가 높을수록 장비 발동 주기 단축
- 연쇄 폭심: 일정 연쇄마다 플레이어 중심 폭발
- 연쇄 회수: 일정 연쇄마다 체력 회복
- 전리품 공명: 연쇄가 높을수록 자석 범위 증가

## 정예 구분과 보상

### 중간보스

- 청록색 마름모 표식과 `중간보스` 라벨
- 일반 보스보다 낮은 체력과 보상
- 처치 시 보유 장비 1중첩 또는 일반 패시브 1중첩을 즉시 획득
- 보스 특수 패시브 선택창은 열지 않음

### 일반 보스

- 분홍색 대형 회전 고리와 `보스` 라벨
- 처치 시 3개의 보스 보상 중 하나 선택
- 보상 종류: 보스 특수 패시브 또는 현재 보유 무기 특수효과

### 공허 보스

- 보라색 표식과 `공허 보스` 라벨
- 일반 보스 보상과 중복되지 않는 공허 전용 보상

### 초월체

- 금빛 표식과 `초월체` 라벨
- 독립 등장 장면과 전용 유산 보상
- 첫 등장 10분, 이후 10분 간격

## 맵 이벤트

### 공통 규칙

- 동시에 하나의 이벤트만 활성화한다.
- 이벤트 표식은 접근하기 전까지 유지한다.
- 이벤트 전투장과 입구 연출은 이벤트 종료 후 제거된다.
- 이벤트 재등장 간격은 보상 선택이 끝난 시점부터 다시 계산한다.
- 모든 이벤트 종료 후 최소 48초 동안 다음 이벤트를 열지 않는다.
- 같은 이벤트는 바로 연속해서 선택하지 않는다.

### 성운 보관소

- 첫 등장 약 42초
- 기본 반복 주기 55~78초
- 같은 유형 재등장 보호시간 95초

### 추락한 우주선

- 첫 등장 약 78초
- 기본 반복 주기 95~135초
- 같은 유형 재등장 보호시간 155초
- 격리 전장 안에서 강화 잡몹 3웨이브

### 공허 균열

- 첫 등장 약 132초
- 기본 반복 주기 170~230초
- 같은 유형 재등장 보호시간 230초
- 전용 차원 전환과 공허 보스

## 블랙홀과 특이점

- 중력 우물은 검은 사건의 지평선과 강착 원반을 사용한다.
- 강착 원반 자체가 원자 궤도처럼 기울어 회전하지 않는다.
- 원반 면은 유지하고 빛나는 입자와 물질 조각이 빠르게 흐른다.
- 에코 비콘 복제 우물은 붉은 강착 원반으로 표시한다.
- 특이점 혈맥은 자홍색 각진 붕괴별로 구분한다.

## 성능 구조

- 적을 숫자형 공간 해시 격자에 배치한다.
- 투사체와 중력 우물은 인접 격자의 적만 검사한다.
- 배열 정리는 매 프레임 새 배열을 만들지 않고 제자리 압축한다.
- 저우선 투사체와 파편을 먼저 제거한다.
- 은하 나선 탄환과 유성 드론 방사탄은 저우선 개체로 분류한다.
- PC와 모바일은 별도의 개체 예산을 사용한다.
- 부하가 높으면 잔상, 파티클, 파편 수를 자동으로 줄인다.
- 경험치 결정은 상한을 넘으면 값을 합친다.
- 지연 공격은 현재 런 식별자가 일치할 때만 실행한다.
- 발사체 색상은 Canvas 그라디언트에 전달하기 전에 유효한 CSS 색상인지 검사한다.

## 비주얼 우선순위

1. 위험과 적 종류가 즉시 구분되는가
2. 공격 적중과 보스 공격 발동이 강하게 느껴지는가
3. 장비 중첩 전후가 보이는가
4. 공전 장비가 서로 겹치지 않는가
5. UI가 전투 시야를 가리지 않는가
6. 장식이 우주적 분위기를 보강하는가

## 금지 사항

- 모든 장비를 피해량 증가의 다른 표현으로 만드는 것
- 장비 6중첩을 단순 배수 증가로 끝내는 것
- 선택지에 최대 중첩과 내부 캡을 노출하는 것
- 화면을 가리는 불투명 UI
- 공전 장비의 외형과 실제 판정 궤도를 다르게 만드는 것
- 능력 탭을 열기 위해 게임 모드를 변경하는 것
- DOM 감시 콜백이 자신이 감시하는 트리를 다시 쓰는 것
- 경고 장판과 실제 판정이 다른 것
- 성능 문제를 파티클 전체 삭제만으로 해결하는 것
- 새 fix/override 파일을 계속 추가하는 것
