# STACKFALL 게임 정보 및 개발 규칙

마지막 동기화: 2026-07-20

이 문서는 STACKFALL의 실제 게임 규칙, 밸런스 기준, 렌더링 구조와 회귀 방지 조건을 정리한 공식 기준 문서다. `README.md`, 이 문서, `WIKI.md`를 함께 관리한다. 과거 인수인계 문서나 채팅 요약보다 현재 `main` 코드와 이 문서를 우선한다.

## 1. 게임 정의

> 여섯 개의 일반 장비 슬롯과 별도 기본 무기를 중첩해 공격 방식과 화면 구성이 실제로 변하는 우주 생존 액션 게임.

### 핵심 규칙

- 일반 장비 슬롯: 6칸
- 기본 무기: `코어 펄스`, 일반 슬롯과 별도
- 일반 장비: 14종
- 장비 중첩: 1~6
- 패시브: 슬롯 제한 없음
- 치명타 확률 상한: 100%
- 레벨당 기본 피해 증가: 1.1%
- 연쇄 피해: 하드 캡 없음, 소프트 캡 사용
- 초월체: 실제 게임 시간 8분 간격
- 일시정지·능력 탭·선택·보상 중에는 게임 시간과 초월체 예정 시간이 진행되지 않음

### 성장 경험치

```text
레벨 요구 경험치
= 10 + 3.8 × level + 1.35 × level^1.34
```

## 2. 스탯 계산 원칙

같은 이름의 스탯은 중첩 수를 합산해 하나의 계수를 만든다. 같은 패시브를 중첩마다 다시 곱하는 복리 계산은 사용하지 않는다.

```text
출력 증폭 2중첩
= 1 + 0.10 × 2
= ×1.20
```

이름이 다른 피해 계수는 기본적으로 서로 곱한다.

```text
출력 증폭 1중첩 + 거성 사냥꾼 1중첩
= 1.10 × 1.15
= 보스 대상 ×1.265
```

레벨, 출력 증폭, 거성 사냥꾼, 성운 강화, 초월체 유산, 공허 각인, 연쇄 피해와 저체력 과출력은 서로 다른 계층이다.

### 경험치 배율

```text
경험치 배율
= 1
+ 개척 계약 중첩 × 0.30
+ 성운 통찰 중첩 × 0.10
```

### 에코 비콘

- 중첩 0: 복제 확률 0%
- 1중첩부터: `min(60%, 중첩 × 7.5%)`
- 첫 복제: 원본보다 약 64~91ms 지연
- 고중첩 추가 복제: 첫 복제보다 약 90~120ms 추가 지연
- 8중첩: 매 5번째 발동 보장
- 복제 공격: 분홍색 계열

### 연쇄

- 연쇄 과부하와 연쇄 계열 패시브는 1중첩 효율을 낮추고 2중첩 이후 성장률을 높인다.
- 연쇄 피해는 현재 연쇄 수에 따라 증가한다.
- 보스와 초월체는 누적 피해량이 일정 기준에 도달할 때마다 연쇄를 진행한다.
- 잡몹이 없는 장기 보스전에서도 연쇄 추진기·폭심·회수가 작동해야 한다.

### 성좌 프리즘

성좌 프리즘은 플레이어 기준 가장 가까운 적 한 명에게 모든 프리즘을 집중하는 지속 집속 광선이다.

| 중첩 | 효과 |
|---:|---|
| 1 | 프리즘 1개, 기본 출력 ×1 |
| 2 | 프리즘 2개가 같은 최근접 적을 함께 조준 |
| 3 | 집속 단계 ×1 → ×1.65 → ×3.25 |
| 4 | 전환 시간 0.68초, 1.78초 |
| 5 | 최대 출력 ×3.45 |
| 6 | 프리즘 3개, 최대 출력 ×3.65 |

- 표적 판별 기준점은 각 프리즘 위치가 아니라 플레이어 위치다.
- 더 가까운 적이 들어오면 모든 프리즘이 동시에 새 적으로 전환한다.
- 표적 전환 시 각 프리즘의 집속 열을 초기화한다.
- 에코 비콘 복제 광선도 같은 최근접 적을 조준한다.
- `다중 투영 코어`로 추가된 프리즘도 별도 적을 찾지 않고 같은 적을 조준한다.
- 일반 집속 광선 굵기는 시각 표현이며 별도 판정 증가가 아니다.
- `과열 성선` 교차 광선은 보이는 굵기와 실제 판정 폭이 같고 `광자 팽창`에 따라 함께 커진다.
- 부하 상태에서는 시각 광선 빈도만 낮추고 피해 주기는 유지한다.

### 성광 장벽 특수효과

`반사 장벽`은 피격마다 사방 반격 창을 발사한다. 피격 보호막 충전만 게임 시간 기준 3초 내부 재사용 대기시간을 사용한다. 장비 중첩이 제공하는 주기적 자체 재충전은 별도 효과다.

## 6. 초월체

### 등장 규칙

- 실제 게임 시간 8분·16분·24분마다 등장
- 선택·보상·맵 이벤트보다 우선
- 전용 봉쇄장 사용
- 넉백·중력 흡입·시간 정지·이동 봉쇄 면역
- 체력 75%·50%·25%와 전투 시간 조건으로 최대 4페이즈

### 성장 규칙

초월체 능력치는 플레이어 레벨, 무기 중첩, 패시브 중첩을 읽지 않는다. 플레이어 성장은 그대로 유효해야 한다.

첫 초월체는 고유 기본 스탯에 다음 고정 계수를 추가한다.

```text
첫 초월체 체력 = 초월체 고유 체력 × 7.60
첫 초월체 피해 = 초월체 고유 피해 × 2.15
기본 스킬 주기 = 기존 주기 × 0.52
```

두 번째 이후에는 등장 횟수에 따라 이전 배율에 다시 곱하는 누적 복리 강화가 적용된다.

```text
체력 단계 배율 = 2.40, 2.74, 3.08, 3.42 ...
피해 단계 배율 = 1.58, 1.73, 1.88, 2.03 ...
```

패턴 압력과 이동 속도도 등장 횟수의 선형·제곱 항으로 증가한다. 이 구조는 장기 생존 런을 언젠가 끝내는 종결 압력이다.

### 고유 세트피스

#### 시간포식자 아트로포스

- 역회전 탄환륜, 시간 잔상, 시곗바늘 절단
- 준비 후 수초 동안 플레이어를 계속 따라 회전하는 본체 추적광
- 추적광 활성 중에도 다른 시간 패턴 병행

#### 종말 항성 오메가

- 회전 화염선, 예측 낙성, 용광로 탄환륜
- 중앙에 수초간 유지되는 조석 용광핵
- 용광핵은 플레이어를 약하게 당기고 탄환륜·운석·근접 피해 생성
- 종료 시 대형 붕괴 폭발

#### 무명의 마지막 성좌

- 별자리 격자, 사각 감금선, 순간이동
- 회전하는 2~3방향 지속 휩쓸기 광선
- 일정 시간 뒤 사라지는 약화 성좌 전령 소환
- 전령은 보상을 주지 않고 삼중 탄환을 발사

세트피스 재사용 주기는 페이즈와 등장 횟수 압력에 따라 짧아진다.

### 초월체 유산

#### 시간 탈취

- 일정 주기 동안 일반 적과 적 탄환의 시간을 크게 늦춘다.
- 모든 장비의 남은 재사용 시간을 빠르게 줄인다.
- 활성 중 플레이어 주변에 시간 파쇄 피해를 반복한다.
- 중첩 시 지속시간·가속·피해 증가, 발동 주기 감소

#### 미니어처 항성

- 플레이어 주변을 도는 임시 항성 소환
- 가까운 적에게 추적 광선 반복
- 방사형 관통탄 반복
- 수명 종료 시 대형 붕괴 폭발
- 처치 시 다음 항성 주조 시간 단축

#### 살아 있는 성좌망

- 여러 노드가 플레이어 주변을 공전하며 공격선 연결
- 연결선은 적을 반복 절단하고 적 탄환 제거
- 각 노드는 서로 다른 적에게 성광 발사
- 종료 시 전체 폭발
- 보호막 충전 효과가 아님

### 초월체 보상 묶음

초월체를 처치하면 아래 세 항목을 모두 지급한다.

1. 고유 유산 1중첩
2. 일반 패시브 총 3중첩
3. 초월 동력핵

초월 동력핵 효과:

- 최대 체력 +8%
- 완전 회복
- 모든 장비 즉시 재점화
- 플레이어 중심 대형 붕괴파
- 단순 보호막 36 보상은 사용하지 않음

## 8. 능력 탭·선택·UI

- 능력 탭을 열면 게임이 일시정지된다.
- 능력 탭을 닫으면 열기 전의 플레이·일시정지·레벨 선택 상태로 복귀한다.
- 선택 카드는 1·2·3·4 숫자키를 지원한다.
- 이벤트 선택은 전투가 멈추므로 자동 제한 시간을 사용하지 않는다.
- 초월체 HUD는 현재 페이즈를 표시한다.
- 능력 장부는 초월체 유산의 실제 능력과 현재 발동 주기를 표시한다.

### 배경 Canvas 2D

- 배경과 성운
- 중력 우물과 비위험 아군 특수효과

### 전경 Canvas 2D

- 적과 보스
- 적 투사체
- 위험 예고
- 플레이어
- 광선과 중요 전경 효과
- HTML HUD와 안내

화면 계층은 `배경 Canvas → PixiJS 아군 효과 → 전경 Canvas → HTML UI` 순서다. WebGL 실패·컨텍스트 손실·CDN 실패 시 Canvas 폴백으로 복귀한다.

성능 보호 단계는 개체 수만으로 화질을 낮추지 않는다. 측정 프레임 지연이 누적된 경우 효과 밀도와 개체 상한을 줄이고, 심각한 지연이 2.5초 이상 추가 지속된 경우에만 해상도 축소를 허용한다.

## 10. 회귀 방지 규칙

- 런타임 hotfix·override·source-sync 파일을 추가하지 않는다.
- 실제 소유 모듈을 직접 수정한다.
- 성좌 프리즘 표적 선택은 `player.x`, `player.y` 기준 최근접 적 하나다.
- 프리즘별 별도 표적 분산을 다시 추가하지 않는다.
- 초월체에 플레이어 레벨·무기·패시브 성장 보정을 다시 연결하지 않는다.
- 초월체 등장 횟수 누적 강화와 고유 세트피스를 유지한다.
- 마지막 성좌 유산을 단순 보호막 충전으로 되돌리지 않는다.
- 초월체 보상에 단순 보호막 36을 다시 넣지 않는다.
- 배포 지문 생성 전에 JavaScript 문법·영구 계약·소유권 검사를 실행한다.
