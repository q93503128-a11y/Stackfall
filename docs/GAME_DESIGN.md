# STACKFALL 게임·비주얼 설계 기준

마지막 동기화: 2026-07-15

## 한 문장 정의

> 여섯 개의 일반 장비 슬롯과 별도 기본 무기를 중첩해, 공격 방식과 화면 구성이 실제로 변하는 우주 생존 액션 게임.

## 절대 개발 원칙

- 이미지를 생성하거나 외부 이미지 파일을 추가하지 않는다.
- 가능한 한 기존 원본 모듈을 직접 수정한다.
- `index.html`의 스크립트 로딩 순서에서 마지막으로 대입된 함수를 기준으로 분석한다.
- 인게임에 패치 내역, 개발 설명, 내부 계산식과 캡 TMI를 넣지 않는다.
- 선택지에는 실제 효과와 증가 수치를 짧게 표시한다.
- 코드 변경 시 `README.md`, 이 문서, `docs/NEXT_CHAT_HANDOFF.md`를 함께 갱신한다.
- 장시간 런의 개체 누적, 충돌 검사, DOM 재생성과 Canvas 합성 비용을 확인한다.
- 예약형 공격은 현재 런 식별자가 일치할 때만 실행한다.

## 핵심 규칙

- 일반 장비 슬롯: 6칸
- 기본 무기: `코어 펄스`, 일반 슬롯과 별도
- 일반 장비: 14종
- 장비 중첩: 1~6
- 패시브: 슬롯 제한 없음
- 시작 장비 UI: 데스크톱 기준 7개씩 2줄
- 치명타 확률: 최대 100%
- 레벨당 기본 피해 증가: 1.1%
- 연쇄 피해: 하드 캡 없이 로그형 소프트 캡
- 초월체: 10분, 20분, 30분 순서로 등장

## 성장 곡선

### 레벨 요구 경험치

현재 요구량은 다음 형태로 증가한다.

```text
10 + 3.8 × level + 1.35 × level^1.34
```

초반 진행은 유지하되 후반의 과도한 레벨업 빈도를 낮춰 선택창과 DOM 갱신 횟수를 줄인다.

### 레벨 피해 보정

- 레벨당 기본 피해: +1.1%
- 장비 중첩과 패시브가 주된 성장축이다.
- 레벨만 높아졌을 때 모든 무기가 과도하게 강해지는 현상을 방지한다.

### 위협 수준

- 생존 시간 1분마다 위협 수준 +1
- 위협이 상승하면 적 체력, 피해, 이동속도와 원거리 공격 빈도가 함께 증가한다.
- 후반 난도는 적 개체 수만 무한히 늘리지 않고 적의 질적 성장으로도 만든다.

## 성좌 프리즘

성좌 프리즘은 일반 관통 광선과 역할이 겹치지 않도록 단일 표적 집속 장비로 설계한다.

- 1중첩: 프리즘 1개가 한 표적에 광선을 유지
- 2중첩: 프리즘 2개가 별도 표적을 조준
- 3중첩: 지속 조준 시 2단계 출력 개방
- 4중첩: 최대 출력까지 걸리는 시간 단축
- 5중첩: 최대 출력 배율과 광선 굵기 증가
- 6중첩: 프리즘 3개가 3단계 집속 광선 유지

집속 단계:

1. 점화: ×1
2. 용광: ×1.9
3. 소각: ×4.1, 6중첩에서는 ×4.6

표적이 죽거나 사거리를 벗어나면 해당 프리즘의 집속 단계가 초기화된다.

## 공전 장비 궤도

- 순서: 성광 장벽 → 펄스 블레이드 → 성좌 프리즘 → 유성 드론
- 보유한 장비만 계산한다.
- 외형 크기와 공격 판정 크기를 기준으로 다음 궤도를 바깥쪽에 배치한다.
- 외형, 실제 충돌 위치, 발사 위치는 같은 궤도 계산을 사용한다.

## 패시브 표시와 수치

선택지에는 기능과 중첩당 수치를 표시한다.

- 자석 코어: 결정 흡수 범위 +34
- 에코 비콘: 발사·설치형 장비 복제 확률 +7.5%p
- 출력 증폭: 모든 피해 +16%
- 가속 회로: 장비 발동 주기 -10%
- 재생 장갑: 최대 체력 +20, 체력 30 회복
- 벡터 부스터: 이동 속도 +9%
- 취약점 해석: 치명타 확률 +6%p
- 연쇄 과부하: 연쇄 유지시간 +7%, 연쇄 피해 효율 증가
- 개척 계약: 적 체력 +6%, 경험치 획득량 +12%
- 충격 흡수재: 받는 피해 -7.5%
- 거성 사냥꾼: 정예 피해 +12%
- 관통 렌즈: 투사체 관통 +1
- 자가 복원: 4초마다 체력 2.5 회복
- 성운 통찰: 경험치 획득량 +10%
- 임계 과출력: 체력 45% 미만일 때 피해 +14%
- 광자 팽창: 투사체·광선·공격 판정 크기 +10%

최대 중첩, 내부 하드 캡과 소프트 캡 계산식은 선택지에 표시하지 않는다.

## 연쇄 시스템

낮은 중첩에서 과도한 효율이 발생하지 않도록 모든 연쇄 패시브는 중첩 수에 따라 효율 상한이 함께 증가한다.

- 연쇄 과부하: 5연쇄 단위 피해 증가, 로그형 소프트 캡
- 연쇄 유지시간: 기본 중첩당 +7%, 현재 연쇄에 따른 추가 보정은 중첩별 상한 사용
- 연쇄 추진기: 12연쇄마다 주기 단축, 낮은 중첩에서는 단축 폭과 상한 모두 낮음
- 연쇄 폭심: 20연쇄마다 플레이어 중심 폭발
- 연쇄 회수: 30연쇄마다 최대 체력 비례 회복
- 전리품 공명: 현재 연쇄에 따라 자석 범위 증가, 중첩별 상한 사용

## 일반 적

### 공허 유체

기본 근접 추적 적.

### 추적 혜성

낮은 체력과 높은 이동속도의 돌진형 적.

### 성간 보루

높은 체력과 접촉 피해의 중장갑 적.

### 성운 포격체

- 플레이어와 약 285~435 거리 유지
- 옆으로 선회하며 조준 사격
- 위협 수준이 높으면 탄속과 발사 빈도 증가
- 높은 위협에서 2발 분산 사격
- 추락한 우주선에서는 강화 포격체로 등장 가능

## 정예 등장

- 중간보스와 보스는 기존 정예가 살아 있어도 다음 등장 시간이 오면 추가된다.
- 등장 순환: 중간보스 → 중간보스 → 보스
- 동시 정예가 4명 이상이면 성능과 가독성을 위해 다음 등장을 짧게 연기한다.
- 화면 상단에 최대 4개의 정예 체력 바를 표시한다.
- 초월체 직전에는 일반 정예 신규 등장을 잠시 중단한다.

## 초월체

초월체는 일반 보스와 별도의 상위 난도 계층이다.

- 개별 기본 체력 배율: 약 ×2.22~×2.48
- 추가 초월체 체력 배율: ×1.9
- 개별 피해 배율: 약 ×1.34~×1.46
- 추가 피해 배율: ×1.25
- 스킬 재사용 대기시간 추가 감소
- 반복 등장마다 체력·피해·속도 증가

초월체 입장 시 일반 필드와 이벤트를 정리하고 전용 시네마틱을 사용한다.

## 맵 이벤트

### 공통

- 동시에 하나의 이벤트만 활성화한다.
- 이벤트 시작 시 진입 표식을 `consumed` 상태로 만들고 배열에서 제거한다.
- 활성 이벤트 중에는 진입 표식을 그리거나 새로 생성하지 않는다.
- 보상 선택 완료 시점부터 다음 주기를 계산한다.
- 모든 이벤트 종료 후 최소 58초 동안 다음 이벤트를 열지 않는다.
- 같은 이벤트는 바로 연속 등장하지 않는다.

### 성운 보관소

- 첫 등장: 약 50초
- 반복 주기: 72~98초
- 같은 유형 보호시간: 125초

### 추락한 우주선

- 첫 등장: 약 92초
- 반복 주기: 118~158초
- 같은 유형 보호시간: 185초
- 강화 잡몹 3웨이브
- 이벤트 잡몹 체력 약 ×1.82~×2.35
- 이벤트 잡몹 피해 약 ×1.48~×1.72
- 이벤트 잡몹 경험치 ×1.5
- 전투 중 진입 포탈과 화면 가장자리 진입 화살표를 다시 표시하지 않는다.

### 공허 균열

- 첫 등장: 약 148초
- 반복 주기: 190~255초
- 같은 유형 보호시간: 270초

## 안내 화살표

보스와 이벤트는 서로 다른 색·아이콘·라벨을 사용한다.

- 중간보스: 청록색 `◇`
- 일반 보스: 분홍색 `◆`
- 공허 보스: 보라색 `◉`
- 초월체: 금색 `✦`
- 성운 보관소: 청록색 `◇`
- 추락한 우주선: 주황색 `⌁`
- 공허 균열: 보라색 `◉`

화면 아래쪽 화살표는 하단 장비 HUD와 겹치지 않도록 데스크톱 154px, 모바일 180px의 안전 영역 위에 배치한다.

## 성능 구조

- 적을 160px 공간 격자에 분류한다.
- 투사체와 중력 우물은 인접 격자의 적만 검사한다.
- 배열은 새 배열 생성 대신 제자리 압축을 우선한다.
- 투사체는 무기별 사거리 초과 시 제거한다.
- 일반 적 최대 예산은 데스크톱 88, 모바일 64이며 부하 시 더 낮아진다.
- 데스크톱 투사체 기본 예산은 210, 부하 시 155이다.
- 과부하 시 피해 숫자, 파티클, 잔상과 저우선 파편을 우선 감소시킨다.
- 혜성 파편, 별가루, 은하 나선, 드론 방사탄과 반사 보조탄은 저우선 개체다.
- 경험치 결정은 상한을 넘으면 값을 합친다.
- 블랙홀 입자 수는 부하 상태에서 자동 감소한다.

## 능력 탭

- `I` 또는 `Tab`으로 연다.
- 능력 탭은 별도 UI 열림 상태를 사용하며 게임 진행 `state.mode`를 바꾸지 않는다.
- 플레이 중에는 시간, 적, 무기, 투사체와 렌더링이 계속된다.
- 레벨업과 보상 모달이 우선한다.
- 장비 상세 카드에서 사거리, 발동 주기와 중첩별 효과를 확인한다.

## 수정 후 필수 QA

- 14개 시작 장비가 7개씩 두 줄로 표시되는지
- 레벨 요구 경험치와 레벨당 피해 증가가 실제 수치와 일치하는지
- 모든 무기가 정해진 사거리 밖의 적을 공격하지 않는지
- 투사체가 최대 사거리에서 제거되는지
- 성좌 프리즘이 표적 유지에 따라 3단계로 강해지는지
- 중간보스 또는 보스가 살아 있을 때 다음 정예가 추가되는지
- 원거리 잡몹이 거리를 유지하고 사격하는지
- 우주선 이벤트 시작 후 진입 포탈이 다시 표시되지 않는지
- 보스·이벤트 화살표가 하단 HUD에 가려지지 않는지
- 10분 이상 플레이에서 개체 수와 프레임이 안정적인지
- 데스크톱과 모바일 콘솔 오류가 없는지
