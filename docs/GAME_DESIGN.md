# Stackfall 게임·비주얼 설계 기준

## 한 문장 정의

> 여섯 개의 장비 슬롯을 어떻게 쌓을지 결정하고, 제한 없는 패시브로 그 장비들의 규칙을 폭주시켜 살아남는 웹 생존 로그라이크.

## 핵심 재미

### 1. 누적의 가시성

획득한 장비와 패시브가 숫자로만 강해져서는 안 된다. 투사체 수, 궤도, 범위, 색, 잔상, 충격파, 화면 흔들림이 단계적으로 커져 플레이어가 성장한 이유를 즉시 알아볼 수 있어야 한다.

### 2. 공명 선택

동일 장비는 2·4·6중첩마다 새로운 규칙을 얻는다.

- 2중첩: 장비의 정체성을 강화하는 변화
- 4중첩: 다른 빌드와 연결되는 변화
- 6중첩: 화면과 전투 규칙을 바꾸는 완성 효과

6중첩은 강해야 하지만, 여섯 슬롯을 모두 사용한 대가로 대응 폭이 좁아진다.

### 3. 비공격 장비의 전략성

공격 장비만 정답이 되지 않도록 다음 역할을 동등하게 취급한다.

- 방어: 보호막, 피해 무효, 반격
- 제어: 흡입, 밀치기, 감속, 시간 제어
- 성장: 경험치 회수, 보상 증폭, 위험 계약
- 지원: 다른 장비 복제, 재사용 대기시간 개입
- 이동: 순간이동, 돌진, 경로 생성

## 디자인 원칙

### 우선순위

1. 적과 위험이 한눈에 보이는가
2. 공격이 적중했다는 감각이 즉시 오는가
3. 장비 중첩 전후가 시각적으로 구별되는가
4. UI가 전투 시야를 가리지 않는가
5. 장식 요소가 분위기를 보강하는가

### 전투 피드백 묶음

강한 사건은 한 가지 연출로 끝내지 않는다.

- 적중: 적 흰색 플래시 + 작은 파티클 + 짧은 효과음
- 치명타: 큰 피해 숫자 + 강한 파티클 + 미세 흔들림
- 정예 처치: 히트스톱 + 큰 충격파 + 화면 플래시 + 저음/상승음
- 공명 개방: 플레이 중지 + 전용 배너 + 화면 흔들림 + 다단 상승음

### 색상 역할

- 청록: 플레이어, 절단, 흡수
- 보라: 중력, 제어, 미지
- 분홍: 복제, 연쇄, 위험
- 노랑: 경험치, 보상, 치명타
- 초록: 방어, 회복, 보호막
- 빨강: 피해, 화염, 위험

희귀도보다 **기능 역할**에 색을 고정해 전투 중 판독성을 높인다.

## 현재 프로토타입 장비

| 장비 | 역할 | 2중첩 | 4중첩 | 6중첩 |
|---|---|---|---|---|
| 펄스 블레이드 | 근접 공격 | 쌍성 궤도 | 절단 파동 | 천체 분쇄기 |
| 엠버 캐스터 | 원거리 공격 | 연발 점화 | 화염 분열 | 초신성 탄두 |
| 불워크 드론 | 방어·반격 | 연결 장갑 | 보복 방벽 | 이동 요새 |
| 중력 우물 | 제어·집속 | 조석 고정 | 붕괴핵 | 쌍둥이 특이점 |
| 자석 코어 | 성장·수집 | 과충전 흡수 | 회수 충격 | 전장 회수 |
| 에코 비콘 | 지원·복제 | 잔향 | 반향 연쇄 | 무한 회랑 |

## 확장 목표

### 1차 콘텐츠 목표

- 장비 24종
- 패시브 60종
- 캐릭터 6종
- 일반 적 18종
- 정예 적 6종
- 보스 4종
- 맵 테마 3종

### 장기 목표

- 장비 60종 이상
- 패시브 180종 이상
- 장비마다 고유 2·4·6 공명
- 공명끼리 상호작용하는 복합 시너지
- 일일 시드, 도전 모드, 무한 모드

## 금지 사항

- 모든 장비를 공격력 증가의 다른 표현으로 만드는 것
- 6중첩을 단순히 피해량 6배로 처리하는 것
- 화면을 가리는 불투명 UI
- 의미 없이 어둡기만 한 배경
- 적과 투사체가 배경에 묻히는 색 조합
- 성장 억제를 위해 강한 조합을 일괄 하향하는 것
