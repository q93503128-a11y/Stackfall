# STACKFALL 게임·비주얼 설계 기준

마지막 동기화: 2026-07-15

## 한 문장 정의

> 여섯 개의 일반 장비 슬롯과 별도 기본 무기를 중첩해 공격 방식과 화면 구성이 실제로 변하는 우주 생존 액션 게임.

## 절대 개발 원칙

- 외부 이미지 파일을 추가하지 않는다.
- 가능한 한 기존 원본 모듈을 직접 수정한다.
- `index.html`의 스크립트 로딩 순서에서 마지막 함수 대입을 기준으로 분석한다.
- 인게임에 패치 내역, 개발 설명, 내부 계산식과 캡 TMI를 넣지 않는다.
- 선택지에는 실제 효과와 중첩당 수치를 짧게 표시한다.
- 코드 변경 시 `README.md`, 이 문서, `docs/NEXT_CHAT_HANDOFF.md`를 함께 갱신한다.
- 장시간 런에서는 적 수뿐 아니라 충돌 검사, DOM 갱신, 그림자, 그라디언트, 파티클, Canvas 내부 해상도를 함께 점검한다.

## 핵심 규칙

- 일반 장비 슬롯: 6칸
- 기본 무기: `코어 펄스`, 일반 슬롯과 별도
- 일반 장비: 14종
- 장비 중첩: 1~6
- 패시브: 슬롯 제한 없음
- 치명타 확률: 최대 100%
- 레벨당 기본 피해 증가: 1.1%
- 연쇄 피해: 하드 캡 없음, 로그형 소프트 캡
- 초월체: 10분 간격

## 성장 곡선

### 레벨 요구 경험치

```text
10 + 3.8 × level + 1.35 × level^1.34
```

후반 레벨업 빈도를 낮춰 선택창과 DOM 갱신이 지나치게 자주 발생하지 않게 한다.

### 피해 보정 원칙

- 같은 이름의 스탯은 중첩 수를 합산해 하나의 계수를 만든다.
- 이름이 다른 피해 계수는 기본적으로 서로 곱한다.
- 출력 증폭: `1 + 중첩 × 0.16`
- 거성 사냥꾼: 정예 대상 `1 + 중첩 × 0.10`
- 출력 증폭 1중첩과 거성 사냥꾼 1중첩의 보스 대상 배율은 `1.16 × 1.10 = 1.276`이다.
- 레벨, 성운 강화, 초월체 유산, 공허 각인, 연쇄, 저체력 과출력도 각각 별도 계층으로 적용한다.
- 같은 이름의 스탯을 중첩마다 다시 곱하는 복리식 계산은 사용하지 않는다.

### 경험치 패시브

- 성운 통찰: 경험치 +8%
- 개척 계약: 적 체력 +5%, 경험치 +14%
- 두 효과는 모두 `경험치 획득량`이라는 같은 스탯이므로 합산한다.
- 개척 계약은 위험을 감수하는 대신 성운 통찰보다 높은 보상을 준다.

### 위협 수준

- 생존 시간 1분마다 위협 +1
- 위협 상승 시 적 체력, 피해, 이동속도, 원거리 공격 빈도가 함께 증가
- 후반 난도는 적 개체 수만 늘리지 않고 적의 질적 성장으로도 만든다.

## 패시브 수치

- 자석 코어: 결정 흡수 범위 +34

- 가속 회로: 장비 주기 -10%
- 재생 장갑: 최대 체력 +20, 체력 30 회복

- 취약점 해석: 치명타 +6%p

- 개척 계약: 적 체력 +5%, 경험치 +14%
- 충격 흡수재: 받는 피해 -7.5%

- 관통 렌즈: 관통 +1

- 연쇄 유지시간: 중첩당 +7%
- 연쇄 추진기: 12연쇄마다 주기 단축
- 연쇄 폭심: 20연쇄마다 플레이어 중심 폭발
- 연쇄 회수: 30연쇄마다 최대 체력 비례 회복
- 전리품 공명: 연쇄에 따라 자석 범위 증가

낮은 중첩에서는 효율과 최대 효과가 모두 낮아야 한다.

## 적과 정예

### 일반 적

- 공허 유체: 기본 근접 추적
- 추적 혜성: 빠른 돌진형
- 성간 보루: 높은 체력의 중장갑
- 성운 포격체: 거리를 유지하는 원거리 적

### 정예 등장

- 순환: 중간보스 → 중간보스 → 보스
- 기존 정예가 살아 있어도 다음 시간이 되면 추가 등장
- 동시 정예 4명부터 다음 등장을 잠시 연기
- 초월체 직전에는 일반 정예 신규 등장 중단

### 정예 체력

- 중간보스는 기존 체력 유지
- 일반 보스는 이전 최종 체력에서 약 12% 감소
- 공허 보스는 이전 최종 체력에서 약 8% 감소
- 초월체는 일반 보스보다 훨씬 강한 체력·피해·스킬 빈도를 유지

### 보상

- 중간보스: 보유 장비 +1 또는 일반 패시브 +1
- 일반 보스: 특수 패시브 또는 보유 무기 특수효과 선택
- 공허 보스: 공허 전용 보상
- 초월체: 고유 유산

## 맵 이벤트

- 모든 이벤트 종료 후 최소 58초 간격
- 같은 종류 연속 등장 금지
- 주기는 보상 선택 완료 시점부터 재계산
- 이벤트 활성 중 진입 표식 배열을 비움
- 우주선 이벤트는 진입 즉시 표식을 소비하며 전투 중 재표시하지 않음

## 성능 설계

### 현재 병목 원인

- Canvas 2D에서 투사체마다 그라디언트, `shadowBlur`, 궤적, `save/restore`를 개별 실행한다.
- 배경은 매 프레임 전면 그라디언트, 성운 방사형 그라디언트와 별을 다시 그린다.
- 광선, 부메랑 곡선, 파티클, 피해 숫자와 보스 표시가 같은 메인 스레드에서 처리된다.
- 충돌 계산뿐 아니라 그리기 명령 수와 픽셀 채우기 비용이 함께 커진다.

### 충돌과 개체 관리

- 숫자형 공간 해시 격자 사용
- 투사체와 중력 우물은 인접 셀의 적만 검사
- 배열은 새 배열 생성보다 제자리 압축 우선
- 경험치 결정은 상한 초과 시 값 병합
- 저우선 파편을 먼저 폐기

### 프레임 적응형 품질

실제 프레임 시간과 현재 개체 수를 함께 사용해 3단계 품질을 적용한다.

1. 정상
   - 전체 적·배경·투사체 비주얼 유지
2. 감소
   - 적·투사체·파티클 상한 축소
   - 배경 성운을 제거하고 별 밀도 감소
   - 투사체를 그라디언트와 그림자 없는 단순 렌더러로 교체
   - Canvas 내부 해상도를 기본의 82%로 낮춤
3. 긴급
   - 일반 적을 단순 도형으로 렌더링
   - 배경을 단색과 소수 별로 단순화
   - 아군·적 투사체를 최소 도형으로 렌더링
   - 블랙홀을 단순 사건의 지평선과 강착 원반으로 표시
   - 광선·곡선·파티클을 최소화
   - Canvas 내부 해상도를 기본의 68%로 낮춤

성능이 회복되어도 해상도는 즉시 오르지 않고 충분히 안정된 뒤 한 단계씩 복구한다.

### 고해상도 제한

- 데스크톱 Canvas DPR 상한: 1.75
- 모바일 Canvas DPR 상한: 1.35
- CSS 화면 크기는 유지하고 내부 렌더링 픽셀 수만 줄인다.

### 아군 투사체 숨기기

- 설정에서 수동으로 켜는 최후 수단이다.
- 아군 탄환, 광선, 부메랑 곡선과 전투 파티클을 렌더링하지 않는다.
- 실제 공격 판정과 피해 계산은 계속 진행한다.
- 적 투사체, 보스 장판, 위험 예고는 항상 표시한다.

### 부하 상태 추가 규칙

- 일반 적 처치 파티클 최소화
- 일반 적 처치 충격파 생략
- 보스와 중간보스의 핵심 타격 연출은 유지
- 보스 경험치 결정 수를 줄이되 총 경험치는 유지
- 일반 타격 효과음 호출 빈도 제한
- 화면 밖 투사체는 그리지 않음

## 인터페이스

- `I` 또는 `Tab`: 능력 탭
- 패시브 선택지는 실제 수치 표시
- 보스와 이벤트는 서로 다른 색·아이콘 사용
- 화면 아래 안내는 무기 HUD 위 안전 영역 사용
- 설정에 `아군 투사체 숨기기` 제공

## 금지 사항

- 같은 스탯을 중첩마다 복리식으로 곱하는 것
- 이름이 다른 피해 계수를 임의로 하나의 합산 계수로 합치는 것
- 위험 없는 경험치 패시브가 위험형 패시브보다 효율이 높은 것
- 성능 문제를 단순히 모든 위험 표시까지 삭제해 해결하는 것
- 선택지에 최대 중첩과 내부 캡을 노출하는 것
- 게임 안에 패치 내역을 표시하는 것
- 새 fix/override 파일을 계속 추가하는 것
