# Stackfall third-party audio

Stage 1 uses externally hosted CC0 audio. The game loads these files only when Stage 1 is played; no account, API key, analytics, or ad service is involved.

## Dark Sci-Fi Audio Pack — SRG774

Source: https://opengameart.org/content/dark-sci-fi-audio-pack  
License: CC0 1.0 Universal / Public Domain  
Stackfall use:
- `sector.mp3` — Stage 1 exploration/combat bed
- `victory.mp3` — Stage clear sting

Runtime mirrors:
- `https://raw.githubusercontent.com/S-H-GAMELINKS/termfront/master/data/audio/sector.mp3`
- `https://raw.githubusercontent.com/S-H-GAMELINKS/termfront/master/data/audio/victory.mp3`

The mirror repository documents the same OpenGameArt source and CC0 license in `data/audio/THIRD_PARTY_NOTICES.md`.

## Epic Boss Battle — Juhani Junkala / SubspaceAudio

Source: https://opengameart.org/content/boss-battle-music  
License: CC0 1.0 Universal / Public Domain  
Stackfall use:
- transcoded `boss.ogg` — Stage 1 boss loop

Runtime mirror:
- `https://raw.githubusercontent.com/jarlah/dungeon-haskell/master/assets/music/boss.ogg`

The mirror repository documents the original OpenGameArt source, CC0 license, and OGG transcode in `assets/CREDITS.md`.

Attribution is not required by CC0, but provenance is retained here for maintenance.
