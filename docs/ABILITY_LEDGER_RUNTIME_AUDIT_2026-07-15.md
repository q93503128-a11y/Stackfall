# 능력 탭 런타임 정지 재검사

마지막 동기화: 2026-07-15

## 확인된 원인

기존 능력 탭은 열릴 때 `state.mode='abilityView'`를 사용한다. 메인 렌더 루프는 원래 `playing`만 업데이트하므로, 보정 코드가 한 번이라도 실행되지 않거나 다른 리스너와 충돌하면 시간·적·투사체·무기 발동과 Canvas 렌더링이 모두 멈출 수 있었다.

전체 화면 `backdrop-filter: blur(13px)`도 매 프레임 갱신되는 Canvas 위에서 큰 합성 비용을 발생시켜 실제 정지와 비슷한 프레임 급락을 만들 수 있었다.

## 이번 수정

- `src/render.js`
  - `playing`과 `abilityView`를 모두 라이브 게임 모드로 처리한다.
  - 기존 입력 보정이 실패하더라도 시간, 적 이동, 무기, 투사체, 이벤트와 렌더링이 계속된다.

- `src/ability-ledger-live-guard.js`
  - 모든 기존 스크립트 뒤에 로드한다.
  - 능력 탭이 열린 상태에서 `abilityView`가 남으면 직전의 `playing` 또는 `paused` 상태로 복구한다.
  - 능력 탭이 닫혔는데 `abilityView`가 남은 경우에도 복구한다.
  - 레벨업 조건을 충족하면 능력 탭을 닫고 선택창을 우선한다.
  - 보스 보상, 메뉴, 게임 오버 등 다른 모달이 시작되면 능력 탭을 닫는다.
  - 모바일 플레이 중 숨겨진 터치 조작을 복구한다.
  - 전체 화면 블러를 제거하고 반투명 오버레이만 사용한다.

- `src/runtime-config.js`
  - 예약형 공격은 `playing`뿐 아니라 일시적으로 남은 `abilityView`에서도 실행한다.
  - 이온 사슬 추가 방전, 초신성 후속 파동, 성간 레일 잔광, 은하 나선 시간차 탄막이 능력 탭을 여는 순간 사라지지 않는다.

## 함께 막은 부수 버그

1. 능력 탭을 연 채 경험치를 채우면 레벨업이 영구 대기하던 현상
2. 능력 탭을 연 순간 예약형 공격이 취소되는 현상
3. 탭을 닫은 뒤 내부 모드만 `abilityView`로 남는 현상
4. 모바일에서 능력 탭을 연 뒤 조이스틱이 계속 숨겨지는 현상
5. 고비용 배경 블러로 Canvas가 멈춘 것처럼 보이는 현상

## 필수 확인 순서

1. 플레이 중 `I`와 `Tab`으로 각각 열기
2. 열린 상태에서 상단 시간이 계속 증가하는지 확인
3. 적, 투사체, 공전 장비와 쿨다운 원형이 계속 움직이는지 확인
4. 은하 나선 또는 성간 레일의 후속 공격 도중 탭을 열어 공격이 이어지는지 확인
5. 경험치가 가득 차면 능력 탭이 닫히고 레벨업 선택창이 뜨는지 확인
6. `Escape`, X, 닫기 버튼으로 닫은 뒤 이동과 공격이 정상인지 확인
7. 일시정지 메뉴에서 능력 탭을 열었을 때만 게임이 정지 상태를 유지하는지 확인
8. 모바일에서 탭을 닫은 뒤 조이스틱이 돌아오는지 확인

브라우저 실플레이를 하지 않고 코드만 확인한 상태에서는 완료로 단정하지 않는다. 배포본에서 위 순서를 직접 확인해야 한다.
