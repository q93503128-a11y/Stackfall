## Stage 1 review

4개의 실제 몸체 OBB를 렌더·무기 적중·접촉이 공유한다. 공격 물체는 최대 6개, 경고와 실제 이동을 구분한다. 모바일 셔터의 통로는 최소 100px이며 크기 축소 후에도 주 실루엣을 유지한다. GPU가 담당하지 않는 독립 물체는 단일 Canvas에서 그대로 그린다. 60Hz 고정 시뮬레이션으로 x2는 두 번의 동일한 물리 스텝을 실행하며, 고속 공격에는 segment 검사를 적용한다. 스테이지 시작·보스 프리뷰·페이즈·격파에서 잔류 물체를 정리한다.

검증: Stage 1 40/40, 실제 geometry 12개, 전 Stage 계약과 공용 회귀/ownership, 전체 src syntax. 실제 Chromium 1440×900 GPU 및 Canvas, 390×844 Canvas에서 정상 4:55→5:00 트리거, 등장, 4개 공격, 48% 전환, 격파 본체 렌더 호출과 보상 결과를 검사한다. 스크린샷을 직접 확인한다. 테스트는 상용 음원 품질이나 타 게임보다 뛰어난 재미를 보증하지 않으며 최종 실플레이 평가는 별도로 필요하다.

기존 stale 검사 정정: save schema 6, 이벤트 8종과 현 간격, S18 다중 투영 3중첩 해금, 실제 드론 raster 178×78, 달 궤도 .56초, 현재 메타 수치표/결과 그래프 DOM, 보스 HUD 145px, GPU 30/40/50/60fps, Windows 줄바꿈. 실제 기능은 변경하지 않았다. 별도로 공용 foreground 경로가 승리 렌더 호출을 누락하던 실제 오류를 수정했다.

## Stage 2 design review (before implementation)

1. 핵심: S1 출구의 이온 유체가 거대한 순환기관으로 이어지는 살아 있는 해구. 2. 공간: 중첩 성운 앵커는 유지하고 연속 굴곡 양안과 아래로 흐르는 심층 층을 추가한다. 3. 진행: 65초 압력 증가, 185초 심층 진입, 250초 유맥 가속, 295초 두 심실의 먼 맥박; 개발 시각으로 복원 가능하다. 4. 일반 기믹: 전단 예고 뒤 실제 이온막이 폭을 유지하며 가로질러 흐른다. 5. 조우: 기존 M→M→B와 성운 보관소 유지; 유체 공격은 예고하고 물리 벽을 두지 않는다. 6. 정체성: 해구 전류를 공급하는 순환기관. 7. 실루엣: 비대칭 두 심실과 불규칙 유맥, 정오각 방사 대칭 제거. 8. 등장: 양안의 유체가 서로 다른 속도로 응집하고 같은 심장 몸체를 형성한다. 9. 전투장: 벽 없는 유체 해구; S1 봉쇄장과 구분. 10. 이동: 관성 있는 해류 표류, 모바일에서는 부드러운 가시 범위 보정. 11. 페이즈: 68% 양 심실 분리 / 32% 편심맥·역류. 12. 공격: 유맥 순차 방전, 눈에 보이는 흡기→방향 분출, 큰 구체를 운반하는 횡류. 13. 실물: 흐르는 막·액적과 실제 심실 수축. 14. 경고: 유맥 점등·흡기 흐름·도달 방향, 동작 토큰으로 취소. 15. 전환: 틈이 벌어지고 각 심실이 다른 리듬으로 움직이며 흐름 반전. 16. 격파: 심장이 부풀어 찢어진 뒤 청록/자홍 유체가 반대 방향으로 빠지고 해구가 맑아진다. 17. 연결: 잔류 응결 결정이 S3 유리별 묘역의 전조.

자기검토: S1의 금속 OBB·격벽·강체 돌진을 재사용하지 않는다. S2에는 hard arena를 만들지 않는다. 기존 visualR64 / hitRadius92 / contactR64를 유지하며 주요 유맥 끝은 공격 피격 범위 안에 둔다. GPU의 원형 hostile sprite가 전용 액적을 덮지 않도록 실제 최종 draw owner를 확인한다. 기존 보상·330초 등장·적·이벤트 횟수는 유지한다.


## Stage 2 implementation review

S1의 봉쇄/강체 문법을 복제하지 않고 wall 없는 유체 공간으로 완성했다. 배경의 연속 굴곡 양안은 S1의 직선 항로와 다르며 4개의 시간 기반 환경 상태는 개발 프리뷰에서도 복원된다. 기존 성운 캐시와 성운 유영체를 유지한다. 이온막은 예고 후 움직이는 실제 판정, 액적은 GPU에서도 전용 드로잉으로 보존한다. 심실 외장과 이동을 모바일에서 확인하고 화면 내 전체 hit envelope를 검사한다. 68/32%에서 이전 예약 행동을 취소한다. 동일한 몸체가 등장/전투/배액 격파를 담당한다.

검증: Stage 2 계약 30개, 전 Stage·공용 회귀·ownership·전체 syntax·fingerprint. 실제 Chromium GPU/Canvas/모바일에서 5:25→5:30 정상 트리거, 3개 공격군, 두 페이즈 전환, radius 64/92/64 분리, 배액 렌더와 클리어 결과. 실제 음원 녹음/청취를 통한 음악 품질 평가는 아직 수행하지 않았다.

## Stage 3 design review (before implementation)

1. 핵심: 해구에서 응결한 별을 보관하는 결정 묘역. 2. 공간: 행렬 타일 대신 드문 길쭉한 묘표와 높이가 다른 결정층. 3. 진행: 투명층 노출→각인 점등→묘표 균열→중앙 석관 부상. 4. 기믹: 결정의 굴절 분열과 실제 하강 결정. 5. 조우: 유리날개와 기존 조우/추락 우주선 일정은 유지하고 결정층 사이에서 전투. 6. 초월체: 묘역의 빛을 가두는 성물함. 7. 실루엣: 길쭉한 비대칭 육면 석관, 공전 날개 제거. 8. 등장: 수직 묘표에서 같은 몸체가 들어 올려짐. 9. 전투장: 벽 없는 묘역, 드문 묘표는 장식이고 위험 결정만 판정. 10. 이동: 독립된 세 묘표 사이에서 예고 후 가속·제동. 11. 페이즈: 52% 뚜껑 분리. 12. 공격: 결정 강하 / 굴절 분열 / 뚜껑 개방 절단. 13. 실물: 삼각 결정과 길쭉한 결정 뚜껑. 14. 경고: 실제 도달 외곽과 움직임 준비 자세, 경고 중 무피해. 15. 전환: 뚜껑이 벌어져 내부 수직 틈 노출, 공격 순서 변화. 16. 격파: 석관이 층별로 박리되어 묘역 아래로 가라앉고 각인 소등. 17. 연결: 남은 정지 결정이 S4 시간 회랑의 고정점.

자기검토: S1 격벽/인양·S2 유체막/방향 액적과 다른 다각 결정, 이동은 플레이어 공전이 아니다. 실제 다각형을 몸체와 공격의 공통 판정으로 쓰며 GPU 캐시가 외형을 바꾸지 않게 최종 렌더 소유자에 등록한다. 기존 360초·해금·보상·유리날개는 보존한다.


## Stage 3 implementation review

S1 관문·강체 봉쇄, S2 두 심실·해류와 비교해 수직 결정 석관·독립 묘표 이동·굴절 분열을 선택했다. 행렬 타일 경로를 우회하고 고정 성묘 및 불규칙 묘표를 전용 렌더로 그린다. 몸체 다각형은 무기/접촉에 동일하며 빈 외곽 원은 판정하지 않는다. 공격은 6개 상한·경고 후 실제 이동·상대 swept segment, 페이즈 변경은 예약 행동 토큰을 취소한다. 등장/전투/격파는 같은 몸체를 사용하며 GPU/cached 경로에서도 전용 draw owner가 호출된다.

검증: Stage3 14/14, geometry 16개, 전체 Stage/공용/ownership/syntax PASS; Chromium GPU·Canvas·390px 모바일 각각 PASS, 정상 5:55→6:00, 세 공격, 구조 전환, 외장 피격·고속 segment, 격파 실제 draw 및 HUD 정리·클리어. 화면 직접 검토 후 면 명암과 성묘 보강. S2 최종 캡처의 일회 시간 초과는 재실행에서 세 경로 모두 통과(인프라 일시 오류); 게임 실패로 분류하지 않는다. 음악 장면 코드만 검증했으며 청취 평가는 남는다.

Stage3 호출 보완: 전용 공격 cue가 공용 오디오의 S1/S2 분기 밖에서 무음이 되는 것을 발견해 adapter voice를 연결했다. 유리 배음의 짧은 감쇠·하강과 페이즈/격파별 길이가 실제 WebAudio 호출로 이어진다.

## Stage 4 design review (before implementation)

1. 핵심: 결정 고정점에 걸린 시간 회랑의 이스케이프먼트. 2. 공간: 타일/묘표 대신 끝이 보이지 않는 두 개의 단절된 시간 철로, 거대한 정지 톱니와 계단식 틱. 3. 진행: 시간차 틱→기구 제동→역방향 틱→시간계 부상. 4. 기믹: 움직이는 위험 물체 자체가 정지했다 재개되는 시차. 5. 조우: 시차 방랑체/조난 첫 등장 등 기존 일정을 유지; 일반보스는 철로 사이에서 전투. 6. 정체성: 회랑의 시간을 붙잡는 기계식 영점 조율기. 7. 실루엣: 수평 이스케이프먼트, 한쪽 긴 추·반대쪽 짧은 팔; 원형 시계/방사 초침 금지. 8. 등장: 정지해 있던 철로에 틱이 흐르고 수평 기구가 맞물린다. 9. 전투장: 벽 없는 회랑; 철로는 세계 구조이며 임의 원형 벽 없음. 10. 이동: 수평 왕복 슬라이드와 끝점 제동, P3 실제 이전 위치를 따라 연속 역행. 11. 페이즈: 68% 긴 추 분리 / 30% 고정추 탈락·역행. 12. 공격: 긴 추의 진자 절삭 / 잠시 정지하는 이스케이프먼트 톱니 / 플레이어의 과거 자취를 역행하는 시간 잔상. 13. 실물: 묵직한 시계추·금속 톱니·시간 인장; 단순 굵은 선 금지. 14. 경고: 진자 전체 스윕과 톱니 도달 외곽, 과거 자취 예고. 15. 전환: 추가 빠지고 기구의 방향/공격 정지 시간이 바뀜. 16. 격파: 구동축이 멎은 뒤 추만 떨어지고 회랑의 시간이 다시 정방향으로 흐름. 17. 연결: 멎은 시간 구속이 풀리면서 S5 자기극 폭풍을 해방.

자기검토: S1 직선 강체 돌파·S2 표류·S3 수직 결정 이동과 구분되는 수평 제동/역행. S1 거더처럼 긴 물체를 쓰더라도 기계추의 자체 시간 정지와 회전축을 보여 다른 리듬을 만든다. S3 결정 강하/굴절 분열을 재사용하지 않는다. 시계 몸체 판정은 같은 다각형, 회전추에는 중간 스윕 판정을 추가한다. 390초·보상·적·사건은 보존.

CI 기록: Stage3 원격 syntax/Validate는 성공. live smoke는 배포 fingerprint 자체는 일치하지만 기존 일반 Apex anti-idle 및 DEV awakening isolation 항목에서 실패하며 Stage2 커밋에서도 동일 workflow가 실패했다. 해당 실패는 최종 공용 감사에서 실제 로그·기존 정본과 대조한다. Stage3 세 renderer 런타임은 오류 없이 통과했다.

Stage4 공용 CI 정정: 실제 live 로그의 Stage3 추가 실패는 타일 drawImage 좌표만 허용한 오래된 anchor 검사였다. 이제 실제 worldToScreen/StageCraft.worldPoint 호출의 world 좌표와 parallax에 대한 이동량을 검사한다. DEV Boss now 검사는 0.001초 뒤 강제 스폰을 기대하던 stale 조건이라 4.983초 무전투→정상 5초 트리거→등장 완료→단일 보스로 갱신했다. 기존 각성 signature/리셋 및 일반 anti-idle 실패는 별도 상세 감사 대상이다.

## Stage 4 implementation review

S1 금속 관문과 비교해 회전추의 실제 정지/재개·시간 역행을 리듬으로 선택했고, S2 곡선 해류·S3 수직 묘표와 달리 단절된 수평 시간 철로를 쓴다. 68% 추의 지지부가 벌어지고 30% 반대 고정추가 내려오며 이전 이동을 되짚는다. 추의 동일 다각형을 렌더·외장 피격·접촉·중간 회전 스윕에 사용한다. 톱니 경고는 전체 도달 footprint를 둘러싸고 3분할 이동으로 멈춤이 실제로 보인다.

검증: Stage4 14/14, geometry 16개·authored physics 8개, 전체 Stage·공용·ownership·syntax·fingerprint PASS. 실제 Chromium GPU·Canvas·390px 모바일 모두 PASS, 6:25→6:30 정상 트리거와 단일 등장, 세 공격·두 구조 전환·x2 설정 및 고정 스텝·피격 외장·격파 HUD/클리어·음악 장면·두 효과음 oscillator 호출. 모든 공격의 실물 화면을 추가 캡처해 직접 확인했다. 갱신한 CI 배경/5초 프리뷰 루프는 Stage1~18 전부 실제 브라우저에서 PASS. 청취 품질 및 기존 일반 anti-idle/각성 isolation 상세 검토는 최종 감사에 남는다.

## Stage 5 design review (before implementation)

1. 핵심: 시간 봉인이 풀리며 철편의 자속이 폭풍으로 엉킴. 2. 공간: 큰 비선형 자속 띠와 드문 거대 도체, 타일/회랑/묘표 없음. 3. 진행: 철가루 정렬→자속 증가→도체 점화→극성 폭풍 준비. 4. 기믹: 도체 주변 철편이 안으로 끌렸다 밖으로 튕김. 5. 조우: 도체 기생체와 기존 조우/사건 유지, 도체는 장식과 위험 실물을 명확히 구분. 6. 정체성: 양 극의 자속을 불균형하게 저장하는 쌍극 왕관. 7. 실루엣: 비대칭 S자 자성체·연결된 두 극, U자 관문/원형 왕관/공전 파츠 금지. 8. 등장: 정렬되는 철가루 속에서 같은 자성체의 양 극이 맞물림. 9. 전투장: 닫힌 벽 없이 자속 방향으로 밀리고 열린 회피 공간 유지. 10. 이동: 독립 도체 사이 끌림·반동, 부드러운 가속과 역방향 제동. 11. 페이즈: 58% 두 극의 연결이 벌어지고 상하 극이 전도됨. 12. 공격: 철편 인양→반발 산탄 / 불규칙 도체 방전 / 극성 반전의 연속 밀림과 철편 역행. 13. 실물: 찌그러진 금속 덩어리·가지친 유도 플라즈마·반대로 정렬되는 자속. 14. 경고: 철편 swept footprint와 도체 분기점 점등, 반전 방향을 먼저 표시. 15. 전환: 연결 코일이 끊어져 두 극이 다른 높이/각도, 이동 반동 변화. 16. 격파: 자성체가 탈자되며 양 극이 멀어지고 철가루는 아래로 떨어져 폭풍이 잦아듦. 17. 연결: 자속을 잃은 항로 조각이 S6 성좌핵으로 수렴.

자기검토: S1 격벽/관문 돌진, S2 유체, S3 결정 분열, S4 정지/역행과 구분되는 인력→척력. 반전은 플레이어 좌표 순간 보정 없이 제한된 속도로 작동하며 가시 자속 안에서만 영향을 준다. 기존 420초·해금·보상·도체 기생체는 보존한다. 철편과 몸체의 다각형은 동일 렌더/판정, 최대 6개.

Stage5 모바일 회귀 보완: 첫 S자 몸체 캡처에서 외장이 HUD에 겹치는 실제 문제를 발견했다. 다각 외장 크기로 등장점과 이동 목표를 정하고 부드러운 복귀 속도만 적용했다. S3/S4도 세 렌더 경로 재검증 PASS. S4의 분리된 추 피벗 경고를 같은 실제 피벗에 맞추고 P3 진입 시 분리 높이를 유지하도록 정정했다.

전수 감사 추가 항목: S5는 12,000/−8,500 좌표에서도 자속·철가루·대형 도체를 검증했다. 앞서 만든 S3 묘표와 S4 철로의 먼 월드 좌표 커버리지는 최종 감사에서 별도로 확장/검사한다(원점의 고정 랜드마크만으로 장기 이동을 설명하지 않기). 새 물리 환경 공격에도 정본의 early damage/warning/speed 배율을 연결했고, 격파 시 남은 피해 숫자를 정리해 몸체 연출을 가리지 않게 했다.

## Stage 5 implementation review

앞선 네 Stage의 강한 문법과 비교했다: 물리 셔터, 유체 흡기, 결정 분열, 시계 정지 대신 자성체가 실제 철편의 인력/척력을 전환한다. 세계 공간은 해구 양안이나 철로를 복제하지 않고 분석식으로 이어지는 자속 흐름과 불규칙 철가루·거대 도체다. 원점과 12,000/−8,500 좌표에서도 이어지는 배경을 확인했다. 벽 없는 공간에서 극성 밀림은 연속 제한 속도이고 실제로 보이는 자속 화살표를 따른다. 58% 코일 파열·외장 분리·극 전도, 동일 몸체의 정렬 등장과 탈자 격파로 공간의 사건을 끝낸다.

검증: Stage5 14/14, geometry 16개·authored physics 8개+환경 배율, 전체 Stage/공용/ownership/syntax/fingerprint PASS. Chromium GPU·Canvas·390px 모바일 모두 PASS: 6:55→7:00 정상 트리거, 단일 등장, 세 공격, 58% 구조 전환, x2 설정/고정 스텝, 실제 외장 적중·swept, 모바일 HUD/컨트롤 여백, 재시작 물체 정리, 격파 draw/HUD/클리어, 음악 장면과 실제 두 oscillator cue. 공격/원거리 배경/격파 캡처를 직접 검토했다. 모바일 공용 변경 후 Stage3/4 세 경로도 재검증 PASS. 합성음 청취와 기존 일반 anti-idle/각성 isolation 상세 감사는 최종 감사에 남는다.

## Stage 6 design review (before implementation)

1. 핵심: 서로 다른 파편 항로를 한 출구로 강제 환승시키는 성좌 규모의 전환 중추. 2. 공간: 어긋난 높이의 장거리 연결 도로와 드문 환승 교차점; 월드 전역의 큰 그래프, 작은 타일 금지. 3. 진행: 표류 항로→연결부 점등→전환판 오작동→출구 수렴, 마지막 25초는 먼 중추에만 존재감. 4. 기믹: 서로 다른 경로의 실제 수송 블록이 합류 / 넓은 전환판의 접힘 / 연결 데크의 연쇄 이탈. 5. 조우: 기존 잡몹은 앞 항로에서 넘어온 군집, 기존 wave/조우/보상 유지. 6. 정체성: 붕괴·굴절·시간·자속을 교통 규칙으로 묶는 시설 자체. 7. 실루엣: 왼쪽 불규칙 지지축과 길이가 다른 세 층의 측면 E자 데크; 가운데 원형 코어/방사 팔 없음. 8. 등장: 세 데크가 다른 속도로 레일을 따라 정렬하고 구동축이 마지막에 맞물림, 등장 마지막과 전투 몸체 동일. 9. 전투장: 열린 환승 갈림길, 위험 수송 경로가 진입로/출구를 바꾸며 별도 원형 벽 없음. 10. 이동: 독립 세 정박점 사이 육중한 가속·저속 제동; 후기에는 층을 연속 이동시키며 정박 전환. 11. 페이즈: 70% 상층 데크가 들리고 35% 중층 데크가 옆으로 빠져 구동부 노출. 12. 공격 네 개: 비대칭 두 수송체의 합류 / 넓은 경첩 전환판의 접힘·중간 멎음 / 도로판 세 구간의 연쇄 이탈 / 실제 중층 몸체의 횡단 전환. 13. 실물: 수송 블록, 두꺼운 바닥판, 도로 단면, 보스의 중층 외장; 굵은 선 탄막 없음. 14. 경고: 전체 도달 다각형·접힘 면적·순서 숫자·중층 이동 방향, 최소 1초. 15. 전환: 상층 높이와 중층 길이가 실제로 바뀌고 항로 수렴 방향 전환; 예약 공격 취소/접촉 유예. 16. 격파: 데크가 지지축에서 순차 미끄러져 도로 연결이 해제되고 틈에 다음 별자리의 검은 생장 징후만 남음. 17. 연결: S5 자속을 잃은 항로를 모으다 파괴되어 S7 살아 있는 성운이 빈 연결부를 점유; 공허 균열은 공개하지 않음.

자기검토: S1 셔터/돌진, S2 유체, S3 수직 석관, S4 시계추, S5 자극과 비교해 세 층 교통 시설·개방된 합류·넓은 지형 접힘을 선택했다. 얇은 S1 거더나 S4 긴 진자 대신 두꺼운 데크의 경첩과 면적을 보여 준다. 450초와 성좌 최종 보정/해금 모두 보존. 몸체의 각 데크/공격은 동일 다각형 렌더와 swept 판정, 모바일 전용 축척, 위험 실물 6개 상한. 정상 등장에 남은 일반 적을 정리하는 공용 경로와 큰 외장 spatial 후보 범위도 실제로 검사한다.

참고 원칙: PlatinumGames의 [기계 생명체 디자인](https://www.platinumgames.com/official-blog/article/9863)에서 읽기 쉬운 실루엣과 비대칭 기계 구조, [제작 팀 개발기](https://www.platinumgames.com/official-blog/article/8997)에서 실제 관절 제약에 맞는 동작과 게임 내 반복 검증을 참고했다. 특정 보스 외형/공격은 복제하지 않으며 본 작품의 환승 구조에 적용한다.

## Stage 6 implementation review

S1~5의 셔터/심실/석관/시계/자극과 대비되는 비대칭 3층 중추를 구현했다. 월드 그래프는 12,000/−8,500에서도 이어지고, 서로 다른 진입로가 보스의 정박점으로 연결된다. 네 공격은 수송체 두 대 합류(끝단 사이 118px 회피 간격), 회전 면적 전체를 예고하는 넓은 전환판, 순서대로 이탈하는 세 도로판, 실제 중층 외장 전환이다. 70% 상층 상승을 35% 중층 분리 이후에도 유지하며, 한 번에 P3로 넘어가는 피해도 동일 구조를 연다. 등장·전투·격파에서 같은 판재 명암/외장 분할을 유지한다.

실제 정상 등장 검사에서 남은 일반 적/적 탄을 정리하는 공용 경로를 보강했다. 큰 외장은 원형 판정 없이 실제 다각형을 사용하며 spatial 후보 범위를 외장 크기로 확장했다. 고속 탄 후보 검색도 이전/현재 위치를 잇는 segment 전체를 포함하도록 수정했다. 실제 48,000px/s 투사체로 먼 외장 적중을 검증했다.

## Stage 7 design review (before implementation)
