## Stage 1 review

4개의 실제 몸체 OBB를 렌더·무기 적중·접촉이 공유한다. 공격 물체는 최대 6개, 경고와 실제 이동을 구분한다. 모바일 셔터의 통로는 최소 100px이며 크기 축소 후에도 주 실루엣을 유지한다. GPU가 담당하지 않는 독립 물체는 단일 Canvas에서 그대로 그린다. 60Hz 고정 시뮬레이션으로 x2는 두 번의 동일한 물리 스텝을 실행하며, 고속 공격에는 segment 검사를 적용한다. 스테이지 시작·보스 프리뷰·페이즈·격파에서 잔류 물체를 정리한다.

검증: Stage 1 40/40, 실제 geometry 12개, 전 Stage 계약과 공용 회귀/ownership, 전체 src syntax. 실제 Chromium 1440×900 GPU 및 Canvas, 390×844 Canvas에서 정상 4:55→5:00 트리거, 등장, 4개 공격, 48% 전환, 격파 본체 렌더 호출과 보상 결과를 검사한다. 스크린샷을 직접 확인한다. 테스트는 상용 음원 품질이나 타 게임보다 뛰어난 재미를 보증하지 않으며 최종 실플레이 평가는 별도로 필요하다.

기존 stale 검사 정정: save schema 6, 이벤트 8종과 현 간격, S18 다중 투영 3중첩 해금, 실제 드론 raster 178×78, 달 궤도 .56초, 현재 메타 수치표/결과 그래프 DOM, 보스 HUD 145px, GPU 30/40/50/60fps, Windows 줄바꿈. 실제 기능은 변경하지 않았다. 별도로 공용 foreground 경로가 승리 렌더 호출을 누락하던 실제 오류를 수정했다.
