## 현재 상태

- Stage 1~18의 현재 런타임은 **교체 전 임시 구현**이다.
- 현재 코드가 옛 Stage 이름, boss id, 공격명, 렌더 구조를 사용하더라도 새 디자인 승인으로 간주하지 않는다.
- 특히 기존 Stage 최종 초월체 컨셉은 전부 폐기한다.
- 새 초월체는 Stage 장소·대표 기믹·환경 변화에서 다시 설계한다.
- Stage 1 `폐쇄선`부터 새 품질 기준으로 전면 재제작한다.
- 사용자 Stage 1 실플레이 승인 전 Stage 2~18의 새 초월체 최종안을 확정하지 않는다.
- Stage 6 / 12 / 18은 각 별자리의 spectacle anchor로 유지한다.

## 스토리 전달 규칙

세계관은 직접 설명하지 않는다.

- 장문 내레이션 금지
- 세계관 설명 NPC 대사 금지
- 로그/문서로 사건의 정답을 전달하는 방식 금지
- Stage 시작 줄거리 요약 금지

대신 다음으로 연결을 보여준다.

- 반복되는 구조 규격
- 원경과 다음 Stage 방향
- 손상 흔적과 침식
- 생체조직과 기계 구조의 연결
- 보스 등장/페이즈/격파 후 환경 변화
- 조명, 환경음, 음악 변화
- Stage 9의 공허 전조 → Stage 10의 첫 완전한 Void Rift 공개
- Stage 12의 생체 내부 하드웨어 → Stage 13의 중계 구조 연결

플레이어가 설명을 읽지 않아도 분위기와 반복되는 시각 단서로 `같은 세계를 계속 지나고 있다`고 느껴야 한다.

## 초월체 리셋 규칙

다음 기존 요소를 모두 새로 만든다.

- 이름
- 실루엣
- 재질
- 신체 구조
- 이동 방식
- 공격 패턴
- Stage 기믹과의 관계
- 등장 연출
- 페이즈 변화
- 격파 연출

새 보스는 디자인이 먼저고 이름은 나중이다. `수호자`, `조율기`, `왕관`, `성물함` 같은 자동 생성식 명칭을 습관적으로 붙이지 않는다.

## 새 작업 순서

1. Stage 1 `폐쇄선`의 공간/기믹/초월체를 처음부터 설계한다.
2. 배경·보스·공격·모션·패턴·등장·격파를 하나의 방향으로 통합한다.
3. 실제 브라우저 캡처와 실플레이로 자체 검수한다.
4. 사용자 테스트를 받는다.
5. 승인 후 동일한 **품질 기준**으로 Stage 2~18을 순차 재설계한다.

Stage 1의 디자인 요소 자체를 다른 Stage에 복제하지 않는다. 계승하는 것은 완성도와 검수 수준뿐이다.
