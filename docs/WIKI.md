# STACKFALL 플레이어 위키

## 문서 역할

이 문서는 플레이어용 설명서다. 설계·구현의 최종 정본은 `docs/GAME_DESIGN.md`이며, 코드 감사 기록은 별도 AUDIT 문서에 보존한다. 이 위키는 현재 정본에서 파생해 갱신하며 독립적인 새 규칙을 만들지 않는다.

마지막 동기화: 2026-07-20

이 문서는 플레이 방법과 무기·이벤트·보스를 설명한다. 세부 계산과 개발 규칙은 `GAME_DESIGN.md`, 실행·검사 방법은 루트 `README.md`를 우선한다.

## 1. 기본 목표

적을 쓰러뜨려 경험치 결정을 모으고 레벨업 때 무기 또는 패시브를 골라 가능한 오래 생존한다. 기본 무기 **코어 펄스**는 일반 장비 6칸과 별도로 항상 장착된다. 같은 무기는 최대 6중첩이며 중첩에 따라 발사 수, 관통, 범위와 특수효과가 달라진다.

## 2. 조작

- 이동: `WASD` 또는 방향키
- 일시정지: `Esc`
- 능력 장부: `Tab` 또는 `I`
- 모바일: 화면 왼쪽 조이스틱
- 선택 카드: 숫자 `1`·`2`·`3`·`4`

공격은 기본적으로 자동이다.

### 수동 조준

설정에서 `수동 조준`을 켜면 마우스 포인터 근처의 사거리 내 적을 우선 공격한다. 끄면 무기마다 정해진 자동 조준 규칙을 사용한다.

성좌 프리즘은 이미 한 적을 집속 중이라면 마우스를 움직였다는 이유만으로 표적을 바꾸지 않는다. 성운 부메랑은 수동 조준을 끈 상태에서 사거리 안 가장 먼 적을 선택한다.

### 여러 공격체의 표적

한 번에 탄환·드론·나선·광선이 여러 개 나와도 대부분 같은 적을 노린다. `다중 투영 코어`로 추가된 공격체 역시 원본과 같은 표적을 공격한다.

이온 사슬만은 여러 적을 이어 공격하는 고유 구조를 그대로 유지한다. 부메랑은 같은 적을 향하되 좌우 경로가 다르고, 레일 광선은 같은 적을 여러 평행선으로 가른다.

코어 펄스는 더 빠른 주기와 크게 오른 기본·중첩 피해를 사용한다. 유성 드론은 개별 탄과 발사 주기가 모두 강화되며, 4중첩부터 2연사, 6중첩부터 주기적인 8발 집중 탄막을 발사한다. 유성 낙하 표식은 사거리 안에서 현재 체력이 가장 높은 적을 우선한다.

### 성좌 프리즘

성좌 프리즘은 새 적을 발견하면 먼저 **1초 동안 얇은 조준선**을 표시한다. 조준이 끝난 뒤 모든 프리즘이 동시에 피해를 주기 시작한다.

- 표적이 살아 있으면 가급적 쓰러질 때까지 유지
- 잠깐 사거리 경계를 벗어나도 바로 다른 적으로 바꾸지 않음
- 표적이 죽거나 멀리 이탈하면 새 표적 탐색
- 새 표적을 잡으면 집속 단계 초기화
- 에코 광선과 추가 프리즘도 같은 표적 사용
- 화면에 보이는 프리즘 위치와 실제 광선 시작점이 일치

집속 단계는 `×1 → ×1.85 → 최대 출력` 순서다.

- 3중첩 최대 출력: ×3.70
- 5중첩 최대 출력: ×4.10
- 6중첩 최대 출력: ×4.45, 프리즘 3개

보스 특수효과 **과열 성선**은 집속 광선이 주변 적에게 굴절 도약하게 한다.

### 성운 부메랑

자동 조준은 사거리 안에서 가장 먼 적을 선택한다. 여러 칼날은 같은 적을 향해 서로 다른 곡선으로 날아갔다 돌아온다. **기본 외형은 곡선형 에너지 부메랑**이며 달 모양이 아니다. 고중첩의 잔광 경로는 실제 지속 피해를 준다.


### 로컬 프로필

프로필 첫 화면에는 스테이지 진행도, 반복 플레이까지 포함한 누적 스테이지 클리어, 총 출격, 누적 처치, 보스급 처치, 해금 장비와 영구 재화를 우선 표시한다. **CORE는 고정 기본 무기이므로 해금 장비 수에 포함하지 않는다.**

세부 보기는 접어서 열 수 있다. 전투 기록은 **중간보스 / 보스 / 초월체 / 균열 보스 / 우주선 보스**를 따로 세고, 스테이지 기록은 Stage 1~18 각각의 누적 클리어 횟수를 보여준다. 장비 슬롯과 코어 성장 진행량도 전투 기록 아래의 작은 정보 칸에서 확인할 수 있다.


### 개발자 테스트 프로필

`?dev=1`이 현재 URL에 명시된 경우에만 로컬 개발자 테스트 프로필을 활성화한다. 일반 주소로 돌아오면 DEV 버튼과 개발 프로필은 활성화되지 않는다. 실제 로그인이나 서버 계정은 사용하지 않는다. 일반 플레이의 `stackfall.meta.v1`과 개발 테스트의 `stackfall.meta.dev.v1`을 분리해 클리어·재화·해금 기록이 섞이지 않는다.

개발 패널에서는 CORE와 S1~S6을 각각 무기·1~6중첩·각성 여부로 설정하고, 각 슬롯 행의 ↻ 또는 **슬롯 정보 새로고침**으로 현재 런타임 상태를 다시 읽을 수 있다. 전체 무기 빠른 테스트, Stage 1~18 직접 시작, Stage 보스 즉시 진입, Endless 시작, 전투 엔티티 정리, 체력·보호막 회복, **무적 ON/OFF**, **레벨업 불가 ON/OFF**, **Stage 전부 클리어**, 각성 코어 지급, 개발 프로필 전용 영구 재화 무한도 사용할 수 있다. **Tab**으로 패널을 열고 닫으며, 개발 모드에서는 이 키가 능력 장부보다 개발 패널에 우선한다. 입력창·선택창을 조작 중일 때는 Tab의 기본 포커스 이동을 유지한다. `특수능력 보상창` 버튼으로 실제 보스 보상형 특수능력 선택창을 즉시 테스트할 수 있다. **각성 코어는 런 내부 임시 자원**이므로 전투 HUD/각성 선택창에서만 보유량을 확인하며 코어 성장 화면의 영구 재화 지갑에는 표시하지 않는다.

## 4. 무기 각성

각성은 6중첩 무기의 최종 변형이다. **6중첩 무기 + 각성 코어 1개**가 있을 때 레벨업하면 일반 선택지 대신 먼저 붉은 월식 테마의 각성 선택창이 열린다.

- 각성할 무기를 고르면 각성 코어 1개를 소비하고 해당 레벨업은 각성으로 사용한다.
- **각성하지 않는다**를 고르면 코어를 소비하지 않고 원래 일반 레벨업 선택지로 돌아간다.
- 자동 선택 기능이 있어도 각성은 자동 확정하지 않는다.
- 기존 1~6중첩과 보스 보상 특수능력은 각성 후에도 그대로 유지된다.
- 각성의 핵심은 수치가 아니라 **실루엣 변화 + 발동 리듬 변화 + 전용 시그니처 연출**이다.

현재 확정된 첫 7종은 다음과 같다.

- **코어 펄스 → 항성핵**: 플레이어 중심핵 자체가 다층 항성 구조로 변하고, **매 공격마다** 중앙 항성 성창 1발과 보조핵 3발이 같은 표적을 동시에 공격한다. 더 이상 4회마다 보조탄만 붙는 형태가 아니다.
- **펄스 블레이드 → 월식 검륜**: 6중첩 기본 3검에 각성 전용 검륜 2개가 더해져 **5개의 실제 검륜**이 계속 공전한다. 별도의 모임/정렬 공격은 없고 회전 속도가 **1× → 2× → 1×** 범위에서 부드럽게 빨라졌다 느려지는 주기를 반복하며 기본보다 느려지지 않는다.
- **별빛 캐스터 → 성운 성창기**: 평소 탄체부터 긴 적홍색 꼬리의 붉은 유성창 편대로 바뀌며, 4번째 원본 발동의 대형 유성창과 연속 적중 후 굵은 성광 관통탄을 사용한다.
- **성광 장벽 → 천궁 성채**: 여러 성광 성채 파츠가 몸을 두르고 피격 방향으로 전개되며, 전투 중 주변 적에게 성채 광창을 능동 발사한다. 보호막 파괴 시 성채 파츠가 흩어지며 반격파가 터진다.
- **중력 우물 → 쌍성 붕괴**: 청색/주홍 특이점 한 쌍이 공통 중심을 실제로 서로 반대편에서 공전하다가 수명 말기에 나선 합체해 거대한 붕괴를 일으킨다.
- **혜성 창 → 종언 혜성창**: 기본 혜성창은 준비 동작 없이 즉시 발사한다. 각성으로 추가되는 거대한 종언 혜성창만 플레이어 앞에 잠시 떠서 빛을 압축한 뒤 갑자기 초고속으로 전장을 관통한다.
- **성운 부메랑 → 월상 회귀**: 기본의 에너지 부메랑 외형을 은백색 달로 바꾸고, 초승달→보름달→기우는 달 변화와 큰 추가 순환 궤도, 강화 귀환 절단·달빛 파문을 추가한다.

두 번째 확정 6종:
- **성좌 프리즘 → 성좌 왕관**: 표적 주변에 다각 성좌 왕관을 완성하고 최대 집속 시 중심 백색 광주를 발사한다.
- **시간 고리 → 영겁 시계**: 거대한 시계판과 시간륜이 나타나며 주기적으로 적의 시간을 끊고 플레이어 장비만 앞으로 진행한다.
- **이온 사슬 → 천뢰 회로**: 적중 대상이 발광 노드로 남아 전장에 번개 성좌망을 만들고, 회로 완성 시 중심 낙뢰가 떨어진다.
- **초신성 코일 → 극초신성**: 3중 코로나 링을 충전한 뒤 중심 압축에서 3단 대폭발로 이어진다.
- **유성 드론 → 낙성 함대**: 평소 사격도 전투기 편대의 집중 관통 일제사로 바뀌고, 4회마다 공전을 깨고 약 0.7초 편대를 보여준 뒤 실제 기체가 화면을 가로지르는 공격 비행을 한다. 준비 중 기체의 기수는 실시간 우선 표적을 향하고 레이저도 화면상의 각 기체 위치에서 같은 방향으로 발사된다.
- **성간 레일 → 종언 레일포**: 각성 후 매 발사가 공통 beam 렌더러가 직접 그리는 하나의 초대형 지속 에너지파로 바뀐다. 기본 폭 자체를 크게 올렸고 약 0.76초 동안 3회 타격한다. **4번째 발동은 특수능력 보상이 아니라 각성 자체의 과충전 시그니처**로, 약 0.46초 대형 충전륜을 보여준 뒤 약 1.85배 굵고 1.52배 긴 빔을 발사한다. `궤도 파쇄` 특수능력은 이 주기와 별도다.

세 번째 확정 6종:
- **은하 나선 → 창세 은하**: 기본형부터 회전 결절에서 실제 나선 궤적으로 발사한다. 각성 후 정·역회전 팔이 동시에 표적을 감고, 3회마다 완성형 은하가 접히며 창세 핵폭발을 일으킨다.
- **반사 성좌 → 천경 성역**: 성광 장벽과 겹치지 않는 외곽 육각 성역에 6개의 검은 유리 거울판을 배치하고 점선 성좌로 연결한다. 거울면만 실제 적탄 방향으로 돌아서며, 여섯 면이 충전되면 완전 반사를 발사한다.
- **진공 개화 → 흑성 연화**: 씨앗이 검은 별핵을 품은 연꽃으로 변하며, 개화 뒤 약 1.22초 동안 강한 6엽 흡인 영역이 남았다가 마지막에 흑성 폐화로 접힌다.
- **위상 기뢰군 → 위상 성궤**: 이동 경로의 기뢰가 별길 노드가 되고, 5회 배치마다 실제로 그린 경로를 따라 위상 파동이 달리며 필요한 기뢰만 원격 기폭한다.
- **성간 미사일 포드 → 성멸 포대**: 진행 방향 기준 후방 좌우에 2×3 발사관 장갑 랙을 펼치고 평소 주탄두부터 대형 장갑 성멸 미사일로 바뀐다. 3회마다 표적 주변 진입 지점에 집결한 뒤 여러 방향에서 동시에 터미널 돌입한다.
- **궤도 문 → 초공간 대관문**: 고정 관문이 거대한 다중 아치로 바뀌고, 회로 3회 완주마다 모든 관문 경로를 한꺼번에 점등·재배선하는 대전송을 실행한다.

모든 각성은 기존 1~6중첩 성장과 특수능력 호환성을 유지한다. 다만 일반 무기는 각성 시 **기본 공격 자체가 각성 전용 공격으로 크게 바뀔 수 있으며**, 색상/장식만 바뀌는 것을 목표로 하지 않는다.

현재 공통 각성 런타임에는 19종 정의, 6중첩/코어 검사, 붉은 월식 선택창, 거부 후 같은 레벨업의 일반 선택 복귀, 코어 소비와 각성 상태/표시가 연결되어 있다. 자동 레벨업을 켜도 각성은 자동 확정되지 않는다. **각성 시스템은 Stage 6 최초 클리어 후 계정 진행도에 획득되며, 그 전에는 각성 코어가 드랍되지 않고 HUD에도 나타나지 않는다.** 해금 후에는 Stage 1을 포함한 모든 런에서 각성을 사용할 수 있다. 활성 상태에서는 일반보스 1개 확정, Stage 중간보스 35% 확률 1개, Endless 초월체 2개를 지급한다. 스테이지 최종 초월체는 처치 즉시 런이 끝나므로 지급하지 않는다. 남은 코어는 런 종료 시 1개당 기본 Stardust 40으로 환전되고 Stardust 배율이 적용된다. **A1~A19 전 무기의 실제 전투 효과와 전용 외형 1차 구현이 완료**되었다. 마지막 6종은 창세 은하의 3회 주기 완성형 은하 수축, 천경 성역의 6면 완전 반사, 흑성 연화의 1.22초 잔류 꽃잎 영역과 폐화, 위상 성궤의 5배치 경로 주행, 성멸 포대의 장갑형 주탄두 및 3회 주기 집결→동시 돌입, 초공간 대관문의 3회로 대전송을 사용한다. 역나선 은하와 쌍면 반사처럼 후단 덮어쓰기로 빠져 있던 augment 런타임도 각성 전후 모두 다시 연결되어 있다.

전투 중 HUD 우측의 **×1 / ×2** 버튼으로 게임 속도를 바꿀 수 있다. 2배속은 전투 업데이트를 프레임당 2회 진행하며, 자동 레벨업을 사용하면 자동으로 고른 장비/패시브와 중첩 변화가 화면에 순서대로 표시된다.

## 5. 패시브와 연쇄

### 자석 코어

자석 코어는 결정 흡수 범위만 늘리지 않는다. 중첩할수록 범위 안에 들어온 경험치 결정이 플레이어에게 더 빠르게 끌려온다.

### 연쇄 계열

게임 안 설명은 다음처럼 짧게 표시된다.

- 연쇄 과부하: 연쇄 유지시간과 연쇄 피해 증가
- 연쇄 추진기: 12연쇄마다 장비 발동 주기 추가 단축
- 연쇄 폭심: 20연쇄마다 플레이어 중심 폭발
- 연쇄 회수: 30연쇄마다 최대 체력 비례 회복
- 전리품 공명: 현재 연쇄에 따라 결정 흡수 범위 증가

연쇄 회수의 회복량은 이전보다 높아졌다. 보스와 초월체에게 계속 피해를 주면 잡몹이 없어도 누적 피해가 연쇄를 진행한다.

재생 장갑은 중첩당 최대 체력 +28과 즉시 회복 46을 제공한다. 항성 생명핵은 중첩당 최대 체력 +12%다. **자가 복원은 중첩당 초당 체력 1**을 회복한다.

성광 장벽, 반사 성좌, 방벽 성운, 자동 방벽 발생기처럼 서로 다른 지속 보호막 효과를 함께 보유하면 보호막 최대치는 각 효과의 최대치를 합산해 증가한다. 같은 보호막 효과의 반복 획득은 해당 효과의 중첩 성장식으로 계산한다.

## 6. 맵 이벤트

### 성운 보관소

청록색 각형 기록 보관소다. 세 개의 봉인 기록 중 하나를 복원해 피해, 속도, 체력, 자석, 투사체, 방벽 또는 연쇄 능력을 강화한다.

**보스나 중간보스가 살아 있어도 성운 보관소 표식은 나타나고 획득할 수 있다.** 보관소에 접촉해 선택 화면을 열면 전투와 게임 시간이 멈춘다.

### 추락한 우주선

원형 격리 전장에서 방어 함대를 처리한다. 기본 제한시간은 82초이며, 게임 시간이 길어질수록 함대가 강해지고 세 웨이브의 적 수와 제한시간도 증가한다. 보스·중간보스 전투와 겹쳐 새로 시작하지 않는다.

세 번째 우주선 이벤트마다 더 넓은 격리 구역에 거대 기함 **격리함 파멸자**가 나타난다. 기함은 조준 총알, 유도 미사일, 예고 레이저와 인터셉터 증원을 사용한다. 모든 웨이브와 기함을 격파해야 잔해 보상을 얻는다.

중간보스·우주선 잔해·공허의 자동 무작위 중첩은 이미 보유한 무기와 패시브만 강화한다. 강화 가능한 보유 항목이 없으면 보호막 또는 선체 강화로 바뀌며, 미보유 항목이 자동으로 0중첩에서 1중첩이 되지 않는다. 직접 선택하는 레벨업 획득은 그대로 새 장비를 열 수 있다.

### 공허 균열

진입하면 공허 전용 보스를 108초 안에 쓰러뜨려야 한다. 실패하면 실공간으로 방출된다. 일반 정예 전투와 겹쳐 새로 시작하지 않는다.

이벤트 표식을 46초 동안 무시하면 신호가 사라지고 나중에 다시 나타난다.

## 7. 초월체

초월체는 실제 게임 시간 10분마다 등장한다. 일시정지·능력 장부·선택·보상 중에는 게임 시간과 초월체 예정 시간이 진행되지 않는다.

초월체 능력치는 플레이어 레벨·무기·패시브 중첩을 읽지 않는다. 플레이어가 강해진 만큼 강한 상태로 싸울 수 있다. 대신 초월체는 첫 등장부터 매우 강하며 **등장 횟수만으로 누적 복리 강화**된다.

- 첫 초월체: 고유 체력에 추가 7.6배, 고유 피해에 추가 2.15배
- 두 번째: 직전보다 체력 약 2.4배, 피해 약 1.58배 추가
- 세 번째: 직전보다 체력 약 2.74배, 피해 약 1.73배 추가
- 이후: 매번 더 큰 배율과 패턴 압력 누적

### 시간포식자 아트로포스

시간포식자의 추적광은 플레이어 위치에 즉시 꽂히는 레이저가 아니다. 플레이어 방향에서 옆으로 비껴난 곳에서 시작해 0.9초 동안 준비한 뒤 제한된 회전 속도로 전장을 쓸며 따라온다. 광선보다 빠르게 반대 방향으로 움직이면 추적을 따돌릴 수 있다.

시간 잔상, 시곗바늘 절단과 시간 격자는 추적광이 유지되는 동안에도 함께 발생할 수 있다.

### 종말 항성 오메가

봉쇄장 중앙에 조석 용광핵을 유지한다. 용광핵은 플레이어를 약하게 끌어당기고 탄환륜과 운석을 만들며, 종료할 때 크게 폭발한다.

### 무명의 마지막 성좌

별자리 격자, 사각 감금선과 순간이동을 사용한다. 회전하는 다중 휩쓸기와 일정 시간이 지나면 사라지는 약화 성좌 전령도 소환한다.

## 8. 초월체 유산

초월체를 쓰러뜨리면 고유 유산, 일반 패시브 총 3중첩, 초월 동력핵을 모두 받는다. 초월 동력핵은 최대 체력 +8%, 완전 회복, 모든 장비 즉시 재점화와 대형 붕괴파를 제공한다.

### 시간 탈취

일정 시간 일반 적과 적 탄환을 크게 늦추고 모든 장비의 남은 재사용 시간을 빠르게 줄인다. 활성 중에는 주변에 시간 파쇄 피해를 준다.

### 미니어처 항성

플레이어 주변을 도는 임시 항성이 한 적에게 추적 광선을 쏘고 방사형 관통탄을 발사한다. 수명이 끝나면 넓게 폭발한다.

### 살아 있는 성좌망

성좌 노드가 공격선을 연결해 적을 자르고 적 탄환을 지운다. 각 노드는 같은 우선 표적에 성광을 집중하고 지속시간이 끝나면 전체가 폭발한다. **보호막 충전형 유산이 아니다.**

## 9. 능력 장부와 설정

`I` 또는 `Tab`으로 능력 장부를 열면 게임이 일시정지된다. 닫으면 열기 전의 플레이·일시정지·레벨 선택 상태로 돌아간다.

장부의 상세 화면은 실제 현재 수치를 표시한다.

- 자석 코어: 현재 흡수 반경과 추가 흡인 속도
- 성좌 프리즘: 공유 표적, 1초 선딜과 현재 최대 배율
- 성운 부메랑: 가장 먼 적 자동 조준
- 연쇄 추진기: 현재 주기 단축

설정에서는 언어, 소리, 피해량, 아군 투사체, 반짝임, 화면 흔들림과 수동 조준을 조절할 수 있다.

## 10. 난이도

- **쉬움**: 적 체력·피해·속도와 원거리 적 비중 감소, Stardust 보상 ×0.85
- **보통**: 기준 밸런스, Stardust 보상 ×1.00
- **어려움**: 적 체력 1.32배, 피해 1.30배, 속도 1.12배, 원거리 적 등장 비중 1.28배, Stardust 보상 ×1.30. 4분 이후 피해와 속도 압박 추가
- 무기 해금과 Core Shard는 난이도 보상 배율의 영향을 받지 않는다.
- 런 종료 시 남은 각성 코어는 1개당 기본 Stardust 40으로 환전되며 Stardust 획득 배율이 적용된다. 사망·스테이지 클리어·중도 종료에서 모두 처리되고 결과에 변환 내역을 표시한다.

## 11. 전투가 잘 보이게 바뀐 부분

- 녹색 육각 결정은 경험치
- 적 탄환은 진행 방향을 향하는 별도 실루엣
- 화면 밖 정예와 맵 이벤트는 방향·종류·거리 표시
- 펄스 블레이드는 실제 충돌 판정과 같은 고정 궤도
- 플레이어 앞 흰색 표시가 이동 방향 안내
- 마지막 성좌 순간이동은 도착 지점을 먼저 예고하고 도착 후 0.48초 동안 접촉 피해 없음
- 초월체 지속 광선은 공격 판정은 유지하면서 화면 갱신 빈도를 제한해 장시간 전투 렉을 줄임
- 실제 프레임 지연은 렌더 프레임당 한 번만 측정해 2배속의 다중 시뮬레이션 업데이트가 부하 감지를 왜곡하지 않음
- 고해상도 화면에서는 **130만 px 이상부터 내부 해상도 90% + Canvas/WebGL DPR 상한 1.15**를 적용하고, 스테이지 동시 적 수도 현재 성능 단계에 맞춘 spawn budget으로 제한
- 부하가 지속되면 장식 파티클 예산과 Pixi 갱신 빈도를 줄인다. 플레이어 무기·각성·월드 구조·화면 밖 안내는 같은 Canvas 렌더러를 유지하며, 부하 기반 추가 저해상도화나 generic GPU 실루엣 교체를 하지 않는다. 실제 투사체·분열·파편·부메랑·중력 우물·피해 주기는 유지한다.

반짝임 효과를 꺼도 적 탄환과 위험 예고는 남는다. 성능이 불안정한 기기에서는 반짝임과 아군 투사체 표시를 줄여도 보스 위험 표시는 유지된다.

## Run modes

- `endless`: infinite mode with random world events, all enemy families, and recurring Apex encounters. 기본 적에 더해 75초부터 route, 240초부터 bloom, 420초부터 array 계열의 Stage 일반 적 변형이 순차적으로 섞이며, Stage 해금 여부와는 무관하다.
- `stage`: finite operations with authored enemy pools, milestone incidents, recurring environmental gimmicks, stage minibosses, and a stage final boss.
- 최종보스 등장 시간은 Stage 1의 **5:00**에서 Stage 18의 **15:00**까지 증가한다. 시간에 도달하면 보스가 등장할 뿐이며, 실제 클리어는 보스를 처치해야 한다.
- Stage 서브보스는 **중간보스 → 중간보스 → 일반보스** 3연전을 반복한다. S1~2는 2+1, S6은 6+3, S12는 10+5, S18은 16+8까지 증가한다. 동시 조우 상한은 Route 3 / Bloom 4 / Array 5다.
- Stage 1~18의 최종보스는 모두 **초월체(Apex) 카테고리**다. 스테이지별 고유 이름·시그니처 공격·체력 스케일은 유지하지만, HUD/기록/안내에서는 초월체로 묶는다. 내부적으로는 Stage 클리어 흐름을 보존하기 위해 `kind:'stage-boss'`를 유지하고 `bossCategory:'apex'`로 분류한다.
- Stage 1~18 최종 초월체는 공용 공격 패턴을 받지 않는다. 18개 보스가 각각 독립 기술을 소유하며 정지 플레이어도 반복적으로 안전하지 않게 현재 위치/과거 위치/실제 이동 경로/전장 중심을 직접 사용하는 기술을 섞는다. S6은 항로 수렴, S12는 외피가 열리는 개화핵, S18은 전장 중심 재작성과 메인프레임 코어 노출로 각 성좌의 피날레를 대표한다.
- 일반 적 동시 수는 Stage 번호와 진행도에 따라 증가하지만 성능 인식형 spawn budget으로 제한한다. 단순 물량 폭증 대신 기믹과 정예/보스 패턴도 난이도를 담당한다.
- 정상 데스크톱 이론 상단은 Stage 1 약 42체, Stage 18 약 67체이며 콤팩트는 약 34체→53체다. 각 스테이지 자체 cap이 더 낮으면 그 값이 우선하고, 성능 Tier 1/2에서는 상단을 다시 약 92%/80%로 낮춘다.
- 배경의 별과 이동 표식은 플레이어 월드 좌표에 따라 서로 다른 속도로 움직여 항로 이동을 체감할 수 있다.
- 실전 전장도 Endless와 분리된다. Stage 1–6은 파손 항로망, Stage 7–12는 살아 있는 뿌리·개화 구조, Stage 13–18은 중계 격자·릴레이 장치를 월드 좌표 구조물로 추가하며 같은 성좌 안에서는 계열감을 공유한다.
- 스테이지 환경 기믹은 보스 공격과 분리된 렌더/스케일을 사용한다. S1~3 초반은 피해 약 56% 수준·느린 속도·긴 경고로 시작하며 진행도와 Stage 번호에 따라 상승해 후반 Array는 최대 약 122%까지 거칠어질 수 있다. 이 보정은 환경 기믹에만 적용되고 보스 공격에는 적용되지 않는다.
- 은하 지도는 성좌마다 노드 배치와 배경 문법도 다르다. 파편의 항로는 직선 항로망, 심연의 개화는 꽃잎형 곡선 가지와 생체성운, 침묵 중계망은 계단형 직각 회로와 청록 데이터 격자를 사용한다.

The original 14-weapon roster is fully unlockable by Stage 10, then expands to 18 at Stage 11/13/15/17. **Current code has no direct weapon unlock at Stage 12/14/16/18.** Stage 12 and 18 have defined system rewards; Stage 14/16 are intentionally reopened reward slots pending a better progression reward.

### Post-roster weapons

- **Vacuum Bloom / 진공 개화**: kill-fed seeds consume nearby deaths, pull enemies inward, and chain-collapse. Its Devouring Pollen augment absorbs ordinary enemy shots before the bloom and increases the final blast.
- **Phase Minefield / 위상 기뢰군**: lays mines from movement distance or fallback time, supports chain fuses and tripwires, and gains a triangular constellation deployment at six stacks. Afterimage Mine projects a weaker phantom mine near a priority target.
- **Interstellar Missile Pods / 성간 미사일 포드**: visible side pods eject missiles outward first, then ignite and curve toward priority targets. MIRV keeps the main warhead at 100% parent damage and adds two 34% side warheads.
- **Orbital Gate / 궤도 문**: stationary installed gate networks alternate between enemy-side and cast-time-player-side placement. Pulses route through fixed gates; Photon Crossfeed can copy an allied projectile once from the next gate at 55% damage.
- **Projection Core / 다중 투영 코어** compatibility is bounded: before Stage 18 it remains a Nebula Vault-only reward capped at 2 stacks. Stage 18 first clear also adds it to the ordinary level-up pool and raises the cap to 3. It adds primary seeds, mines, main missiles, or routed gate pulses; secondary MIRV warheads, phantom mines, forced blooms, and gate copies do not recursively multiply.

### Galaxy map

The galaxy map is divided into constellation pages. Only one constellation is displayed at a time; after a constellation is completed, the next constellation page becomes reachable when its first stage is unlocked.

The main menu is a mode hub rather than a direct loadout/start screen. `GALACTIC OPERATIONS` opens the galaxy map, `ENDLESS` opens sortie preparation, and `CORE DEVELOPMENT` opens the permanent upgrade field. The upper-left local-pilot card is clickable and shows a detailed local-save panel with clears, runs, kills, equipment slots, unlocked weapons, best Stage 1 time, Stardust, and Core Shards; it is not an online account. The upgrade field keeps the exact shared in-game player-core renderer centered with floating orbital nodes and fits within one normal desktop viewport; compact/mobile layouts may scroll. Future skins can therefore propagate through the shared renderer automatically. Skins are otherwise deferred.

### Stage content identity

Stage environments are authored as distinct places rather than Endless background recolors. Ordinary enemies may be reused across stages, but encounter rhythm and final-Apex identity must change by Stage. Stage 중간 전투는 별자리별 공용 중간보스/일반보스 풀을 사용하되 **M→M→B** 순서를 반복하고 후반으로 갈수록 묶음 수를 늘린다. 보스 수를 늘린 목적에는 성장량 증가도 포함되므로 XP를 임의 삭감하지 않는다. 각성 코어는 일반보스 확정, 중간보스 35%다. 보스 HUD는 현재 살아 있는 조우별 HP 바를 모두 표시하며 쌍둥이 조우만 합산한다.

Final Stage Apex는 공용 보스 풀과 별개다. 18종 모두 독립 기술 세트를 사용하고 공용 Stage-Apex 공격 함수는 금지한다. Route는 붕괴 셔터·심장 맥동·프리즘 감옥·시간절단·쌍극 견인·항로 수렴, Bloom은 포식·굴곡 뿌리·이중나선·거울 교차사격·종자고 수축·외피 개방 개화, Array는 스캔·잡음 셀·외부 채널·등대 스윕·프로토콜 새장/톱날·전장 재작성으로 구분한다. 특히 S6/S12/S18은 각 성좌의 전투 언어를 종합한다.

경험치 결정은 생성 시 가까운 기존 결정에 값을 합쳐 밀집도를 미리 낮추며, 누적 XP가 클수록 결정 크기도 커진다. 기존 엔티티 상한 압축은 최후 안전장치다.

### 시스템 해금

- Stage 1: 코어 성장.
- Stage 3: 보스 특수능력. 이전 일반보스는 현재 무기/패시브 +1, 이후 일반보스는 특수능력 선택 보상.
- Stage 6: **무기 각성 + Endless + Hard 난이도**. 한 번 획득하면 낮은 Stage를 재플레이해도 그대로 사용할 수 있다.
- Stage 6 전에는 각성 코어 자체가 드랍되지 않고 HUD에도 표시되지 않는다.
- Stage 12: 일반 레벨업 4지선다.
- Stage 14 / Stage 16: 무기 해금이 없는 미정 보상 슬롯. `런 시작 레벨 +3` 등 시작 성장 가속을 포함해 후속 설계한다.
- Stage 18: 다중 투영 코어의 일반 레벨업 풀 진입 + 최대 중첩 2→3. 기존 성운 보관소 획득 경로는 유지한다.
- 설정의 **해금 관리**에는 이미 획득한 시스템만 표시하며 각 항목을 개별적으로 끄고 다시 켤 수 있다. 획득하지 않은 기능을 강제로 켤 수는 없다.
- 이벤트는 해금 대상으로 두지 않는다. Boss Rush는 추후 검토한다.
- 현재 Stage 모드는 Endless의 성운 보관소/추락한 우주선/공허 균열 이벤트 런타임을 직접 사용하지 않는다. 이벤트 종류 확대와 Stage 배치는 후속 작업이다.
- DEV 프로필은 획득 조건을 우회하고, 장착 슬롯 V/VI는 코어 성장 내부 확장 노드로 유지한다.

### 코어 성장 돌파

일반 성장 레벨은 성진으로 올리고, 코어 조각은 중간/최종 돌파 단계와 장착 슬롯 V·VI에 집중해 사용한다. 돌파 레벨은 일반 레벨보다 한 번에 더 큰 능력치 증가를 제공한다. 상세 패널은 현재 효과·다음 효과·이번 증가량을 함께 표시한다. **전체 초기화** 시 모든 투자 레벨과 슬롯 해금을 되돌리고 사용한 Stardust/Core Shard를 전액 환불한다.

Stage 13~18의 환경 공격은 같은 방사형 선 패턴을 반복하지 않는다. 중계 스캔 레인, 잡음 격자, 패킷 채널, 블라인드 스윕, 프로토콜 봉쇄, 수축 다각형으로 역할을 분리한다. 스테이지별 월드 배경 구조도 이미 구현되어 있으며 플레이어 이동에 따라 월드 좌표로 움직인다.
